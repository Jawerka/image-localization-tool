# Image Localization Tool Constitution

## Core Principles

### I. Пайплайн v2

Обработка страницы обязана идти через пайплайн v2. Новый путь распознавания, перевода или очистки не подменяет этот вход.

### II. Минимальный diff

Изменение обязано оставаться настолько малым, насколько хватает для задачи. Новый движок — новый файл в `src/components/`. Новая настройка — поле в `Config` со значением по умолчанию.

### III. Русский язык

Комментарии и docstring пишутся на русском.

### IV. Локальные данные

В репозиторий не попадают `models/`, `config.json`, `test-img/`, `data/`, `output/`, `.vendor/`, логи и секреты. Ключ API не записывается в JSON.

### V. Заявленное качество

Число ink recall с локальных эталонов относится только к этим страницам. Его нельзя называть качеством на произвольной странице. Источник цифры — `docs/BENCHMARK_RESULTS.md`.

## Границы совместимости

CLI (`src/main.py`), окно (`python -m src.app`), расширение браузера и LAN-слушатель остаются на месте. Новая фича не убирает существующий вход и не меняет контракт соседней поверхности без отдельного требования.

## Известные ловушки

- RT-DETR `orig_target_sizes` — `[ширина, высота]`.
- LLM обрабатывает запросы по одному. Пустой `llm_model` резолвится через `/v1/models`.
- LaMa дорисовывает буквы, если кольцо однородности захватывает соседний текст.

План, который нарушает одну из этих границ, обязан явно назвать причину.

## Governance

Поправка конституции требует записанной причины, оценки совместимости с уже принятыми принципами и новой версии по semver. MAJOR — принцип удалён или переопределён. MINOR — принцип или раздел добавлен. PATCH — уточнение формулировки без смены правила.

Проверка соответствия этой конституции входит в ревью плана и реализации фичи. Исключение из принципа записывается в плане, а не подразумевается.
