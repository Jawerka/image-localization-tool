# Changelog

Заметные изменения Image Localization Tool. Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), версии — на [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Полный текст заметок к версии 1.0.0 — [docs/RELEASE_NOTES_1.0.0.md](docs/RELEASE_NOTES_1.0.0.md). Это первая версия опубликованного дерева.

## [1.0.3] - 2026-11-15

### Added

- Публичные примеры README повторно обработаны 2026-11-15 на прежних исходниках; обновлены сравнения, отчёты и описание видимых ограничений. Подготовка и импорт используют общую тестовую очередь.
- Быстрое окно Flutter для перевода из FastStone через LAN: последовательная очередь, масштабирование, копирование результата, повтор и открытие в редакторе. Окна быстрого перевода и редактора отдельно запоминают положение и размер.
- Единый `scripts/test_images.py` для полного и выборочного свежего прогона, фоновой очереди, продолжения по хешам и отчётов. Галерея показывает прогресс и ETA, сохраняет оценки, экспортирует JSON и добавляет в комментарий координаты выделенных рамок.

### Fixed

- Свободная мысль или звук рядом с облачком не склеиваются с репликой до OCR. Маска крупных угловатых латинских звуков на белом фоне сохраняет соединённые компоненты букв, не захватывая рисунок на цветной плашке.
- Маски светлых букв и широкой пастельной обводки, остатки пунктуации, ретушь ровных цветных облачков и защита соседнего рисунка.
- Переносы по реальной ширине букв, наклонные подписи и ошибочные привязки к чужому облачку. Автоматические чёрно-белые цвета учитывают фон и сохраняют ручное оформление.
- Пропущенные короткие реплики дополнительно предлагаются локальным OCR и независимо проверяются VLM. Частичная подпись вроде «LATER» может расширяться до полного блока «2 MINUTES LATER» только после независимого чтения всей рамки.

Автоматическая читаемая вёрстка карточек, проверка дополнительных рамок VLM, защита соседнего текста, исправления масок и расширения. Подробности и ограничения: [RELEASE_NOTES_1.0.3](docs/RELEASE_NOTES_1.0.3.md). Подготовка релиза — [план](docs/RELEASE_PLAN_1.0.3.md).

### Fixed

- Release Linux при push уже опубликованного тега больше не собирает sidecar и не пытается загрузить файлы в публичный релиз. Guard до checkout вызывает `gh --repo` и задаёт `GH_REPO`, иначе в пустой папке runner `gh` не видит репозиторий. Ручной `workflow_dispatch` на такой тег по-прежнему завершается ошибкой. Повтор старого запуска Actions не подхватывает этот workflow.

## [1.0.2] - 2026-11-01

Совместимые исправления линии 1.0. Тег `v1.0.1` и его архивы не перезаписываются. Заметки: [docs/RELEASE_NOTES_1.0.2.md](docs/RELEASE_NOTES_1.0.2.md).

### Fixed

- Фильтр маски звуков сохраняет подтверждённые тонкие штрихи внутри надписи. Добавлена проверка настоящих OCR-регионов на шести sound-ref и всём размеченном корпусе: [результаты и оставшиеся пропуски](docs/SFX_RECHECK.md).
- RapidOCR отличает короткие фразы заглавными от звуков и сохраняет адреса автора как подписи; интеграция последних алгоритмов текста/SFX проверена в общем пути распознавания и ретуши.
- Автоматическая маска дополнена светлыми буквами и обратной обводкой; прозрачные плашки сохраняют рисунок при ретуши, тонкие штрихи не возвращаются при смешивании. Добавлен сравнительный прогон локальных эталонов: [подробности и ограничения](docs/AUTOMATIC_RETOUCH.md).
- В релизной базе закреплён `opencv-python-headless==4.13.0.92` рядом с `opencv-python`; RapidOCR ставит оба пакета в один модуль `cv2`.

### Changed

- Версия пакетов и образов 1.0.2.

## [1.0.0] - 2026-11-01

### Added

- Необязательный вход в браузерный редактор по логину и паролю. Учётная запись хранится в `data/web-access.json`.
- Второй детектор текста (`detector_mode`, `ctd_conf`, `ctd_seg_clip`). По умолчанию остаётся основной детектор.
- Кнопка расширения при наведении: очередь, этап и действия на самой картинке.
- Перевод изображения прямо на странице: без боковой панели и без изменения `src`/`srcset`.
- Панель «Оригинал / Убрать» внутри рамки картинки.
- Доступ ко всем сайтам запрашивается один раз при установке расширения.
- Полные поставки Windows и Docker с моделями внутри: офлайн OCR и перевод en↔ru.
- Браузерный редактор в Docker: загрузка, правка и скачивание результата.
- Вкладки региона «Текст / Шрифт / Трансформация» и заморозка раскладки между preview и экспортом.
- Linux-служба с обновлением и откатом; staged-обновление portable-сборки Windows.

### Changed

- CLI пишет журнал в `data/logs/cli.log`. `--verbose` включает подробный вывод. Импорт модуля файл не создаёт.
- README описывает использование. Сборка, тесты и соглашения — в CONTRIBUTING.md.
- Накопленные спецификации заменены одной базой `specs/001-current-state`. Старые тексты — в `legacy/specs/`.
- Каждое обновление `main` публикует Docker-образ `edge-cpu-full`.
- Версия расширения совпадает с версией приложения.
- Тяжёлые компоненты ставятся из официальных колёс PyPI и PyTorch. Манифест хранит адрес, размер и SHA-256 каждого файла.

### Removed

- Перенос ключа LLM из системного хранилища и запись хешей устройств туда же. Ключ остаётся только в `data/llm-api-key.txt`.
- Установка runtime-паков из архивов `.7z` (schema 1). Каталог — schema 2 и колёса.
- PyInstaller больше не включает pywebview: поставка — Flutter-хост.
- Установщик `setup.exe`, сборка паков `.7z` и эксперимент WeVisOne. Windows поставляется только portable ZIP.

### Fixed

- Staged-обновление Windows сохраняет пользовательские каталоги при обновлении и откате.
- Модель Argos освобождается перед сменой направления перевода.
- Ключ LLM уходит во все запросы пайплайна.
- Кнопка «Проверить» отличает неверный ключ от публичного списка моделей.
- Ответы 401/403 не повторяются трижды: быстрее включается RapidOCR + Argos.
