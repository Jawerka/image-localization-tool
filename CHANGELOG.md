# Changelog

Заметные изменения Image Localization Tool. Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), версии — на [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Полный текст заметок к версии 1.0.0 — [docs/RELEASE_NOTES_1.0.0.md](docs/RELEASE_NOTES_1.0.0.md). Это первая версия опубликованного дерева.

## [1.0.0] - 2026-11-01

### Added

- Необязательный вход в браузерный редактор по логину и паролю. Учётная запись хранится в `data/web-access.json`.
- Второй детектор текста (`detector_mode`, `ctd_conf`, `ctd_seg_clip`). По умолчанию остаётся основной детектор.
- Кнопка расширения при наведении: очередь, этап и действия на самой картинке.
- Перевод изображения прямо на странице: без боковой панели и без изменения `src`/`srcset`.
- Панель «Оригинал / Убрать» внутри рамки картинки.
- Доступ ко всем сайтам запрашивается один раз при установке расширения.
- Полные поставки Windows и Docker с моделями внутри: офлайн OCR и перевод en↔ru.
- Браузерный редактор в Docker: загрузка, правка и скачивание результата.
- Вкладки региона «Текст / Шрифт / Трансформация» и заморозка раскладки между preview и экспортом.
- Linux-служба с обновлением и откатом; staged-обновление portable-сборки Windows.

### Changed

- CLI пишет журнал в `data/logs/cli.log`. `--verbose` включает подробный вывод. Импорт модуля файл не создаёт.
- README описывает использование. Сборка, тесты и соглашения — в CONTRIBUTING.md.
- Накопленные спецификации заменены одной базой `specs/001-current-state`. Старые тексты — в `legacy/specs/`.
- Каждое обновление `main` публикует Docker-образ `edge-cpu-full`.
- Версия расширения совпадает с версией приложения.
- Тяжёлые компоненты ставятся из официальных колёс PyPI и PyTorch. Манифест хранит адрес, размер и SHA-256 каждого файла.

### Removed

- Перенос ключа LLM из системного хранилища и запись хешей устройств туда же. Ключ остаётся только в `data/llm-api-key.txt`.
- Установка runtime-паков из архивов `.7z` (schema 1). Каталог — schema 2 и колёса.
- PyInstaller больше не включает pywebview: поставка — Flutter-хост.
- Установщик `setup.exe`, сборка паков `.7z` и эксперимент WeVisOne. Windows поставляется только portable ZIP.

### Fixed

- Staged-обновление Windows сохраняет пользовательские каталоги при обновлении и откате.
- Модель Argos освобождается перед сменой направления перевода.
- Ключ LLM уходит во все запросы пайплайна.
- Кнопка «Проверить» отличает неверный ключ от публичного списка моделей.
- Ответы 401/403 не повторяются трижды: быстрее включается RapidOCR + Argos.
