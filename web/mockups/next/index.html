Image Localization Tool · v2

Радикальный редизайн оболочки: схлопываемые панели, плавающий док инструментов, командная строка, слои и состояния. Статичные экраны без сборщика — открываются из проводника.

Канвас важнее хрома Слои: панели → карточки → поповеры Клавиатура — первый класс Палитра бренда без изменений Справочник состояний и токенов
Редактор Флагман Плавающий док, шторка сравнения, ручки рамок, пилюля «Готово», секционный инспектор, пилюля задания. Пустое окно Зона перетаскивания, недавние проекты, пустые состояния панелей, подсказки клавиш. Глава в работе Очередь со статусами, карточка прогона, заблокированный док, пилюля этапа на сцене. Пакетный прогон Пауза, ETA, фильтры проблем, главы, отчёт с действиями в инспекторе. Стиль региона Список шрифтов с живым образцом, размер и ореол, искривление, стили проекта. Звуки Режим «не трогать / заменять», подобранный стиль, объяснение «почему звук». Настройки Девять разделов, карточки тем, переключатели, черновик ОК / Применить / Отмена. Первый запуск Мастер из четырёх шагов, скачивание моделей с прогрессом. Экспорт Диалог с радио-карточками, резюме «8 страниц → translated», PNG/JPG. Диалоги Хоткеи с поиском, подтверждение выхода, выбор vision-модели, ошибка воркера. Глоссарий Таблица серии с инлайн-редактированием, род, заметки, импорт/экспорт. Доступ по сети Код сопряжения, устройства с отзывом, предупреждение о HTTP.

Тема пишется в localStorage и прокидывается в ссылки. Иконки встраиваются через sprite.js — на file:// внешние <use> блокируются браузером. Изображения — из test-img/.
