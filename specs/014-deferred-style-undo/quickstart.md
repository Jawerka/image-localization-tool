# Quickstart: Deferred Style & Undo

1. Open a page, paint two brush strokes — do not press Done.
2. Ctrl+Z once → only the second stroke disappears; Done still shown if first remains.
3. Change font size in the right panel → Done stays; no full retypeset yet.
4. Press Done → mask + style apply together.
5. Paint again, leave page → confirm/discard/stay dialog still appears.
