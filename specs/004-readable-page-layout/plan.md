# Implementation Plan: Читаемая вёрстка

**Branch**: 004-readable-page-layout | **Date**: 2026-11-02 | **Spec**: [spec.md](spec.md)

## Summary
Белая обводка через существующий auto, проверка контура, подбор целых слов, безопасный fallback; уточнение дополнительного OCR и букв непривязанного диалога.

## Technical Context
Python 3.10–3.13, Pillow/OpenCV/NumPy, PagePipeline/Typesetter. Windows portable и общий Python-код остальных поверхностей. Форматы совместимы, новых настроек нет. Приватные входы и галереи в ignored test-img/output.

## Constitution Check
Пайплайн v2 сохраняется. Минимальный diff существующих компонентов; комментарии по-русски. Ручные настройки и локальное хранение сохраняются. Качество ограничено локальными проверками. Ветка создана обязательным hook. PR/слияние/публикация не разрешены и не выполняются.

## Project Structure
src/components/{typesetter,bubble_layout,adaptive_text,text_discovery,text_segmenter}.py; профильные tests/unit; документация и спецификация.

## Phase 0 — Research
Исследовать сохранённые 286 регионов. Исследование очистки поручено отдельному агенту по workflow plan. Сверить геометрию исходника с финальным рендером.

## Phase 1 — Design
Обводка измеряется и рисуется одним правилом. Контур проходит проверку покрытия исходной рамки. Тело баллона отделяется от хвоста; подбор предпочитает целые слова. Fallback сохраняет все строки с предупреждением. Дополнительный OCR уточняется по буквам с исключением длинных контуров. Непривязанный светлый диалог получает консервативный резервный сбор букв.

## Validation
Профильные unit-тесты; повторная очистка/вёрстка 28 страниц из сохранённых переводов с новой геометрией; последовательный replace-прогон звуков. Галерея до/после и предупреждения. Оставшиеся требования отражаются в tasks.

## Complexity Tracking
Новых движков/сервисов нет. Риск затрагивания рисунка при уточнении формы проверяется по исходнику, маске и очищенному слою отдельно.
