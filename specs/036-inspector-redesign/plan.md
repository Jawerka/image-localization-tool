# Implementation Plan: Современный инспектор
**Branch**: `codex/036-inspector-redesign` | **Date**: 2026-10-18 | **Spec**: [spec.md](spec.md)
## Summary
Перегруппировать карточку региона в секции текста, оформления и положения. Сохранить обработчики и модель сохранения.
## Technical Context
- JavaScript ES modules, CSS; текущий браузер Chromium/WebView2.
- Зависимости и серверные API не меняются.
- Хранилище: существующий документ; состояние details только в DOM.
- Проверки: Node test runner, pytest + Playwright, скриншоты обеих тем.
- Ограничения: ширина 344 px, UI scale, без новых запросов на ввод.
- Объём: один инспектор, текущие поля и действия.
## Constitution Check
До и после проектирования: PASS по всем пяти принципам. Пайплайн, движки и Config не меняются; локальные данные не добавляются; комментарии по-русски; изменения ограничены инспектором.
## Project Structure
- web/js/inspector.js — разметка карточки.
- web/js/inspector_render.js — сохранение раскрытия положения.
- web/css/inspector.css + web/index.html — изолированные стили инспектора.
- tests/e2e/test_ui_smoke.py — проверка сохранения секций и ввода.
- specs/036-inspector-redesign/ — спецификация, план, исследование, модель, контракт, проверки, задачи.
## Implementation phases
1. Разметка текста и действий.
2. Оформление и сворачиваемое положение, сохранение details.
3. Стили, проверки и визуальное сравнение.

## Дополнение: геометрия во вьюпорте
web/js/viewer.js: SVG-связи узлов, перемещение с Shift по одной оси, перемещение текущего preview вместе с рамкой. web/js/inspector.js: вход в режим геометрии, учитывать bbox/текст в ключе preview и ждать whenSaved до запроса. Не заменять серверный рендер приблизительной имитацией текста. Линии сетки обновляются немедленно; точный текст — после сохранения и ответа сервера.
