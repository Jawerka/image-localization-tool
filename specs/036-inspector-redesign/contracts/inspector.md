# UI contract
Сохраняются все data-field и data-region-action, один выбранный регион, keyboard-native кнопки, label/for полей и aria-pressed переключателей. Новая секция details.region-card__position по умолчанию закрыта, её раскрытие сохраняется при rebuild. Сброс стилей сохраняет прежнее поведение: сброс геометрии; подпись уточняется до «Сбросить геометрию».
