# Validation
1. npm run test:js
2. venv/Scripts/python.exe -m pytest tests/e2e/test_ui_smoke.py -q
3. Открыть страницу, выбрать регион; сравнить оригинал/перевод, изменить перевод, размер и цвет.
4. Раскрыть положение, изменить поле, проверить сохранение раскрытия и ввода.
5. Проверить обе темы при 1280×800 и масштаб 125%; отсутствие горизонтального переполнения инспектора.
6. Проверить пропущенный и переполненный регион, пустое состояние и длинный текст.
