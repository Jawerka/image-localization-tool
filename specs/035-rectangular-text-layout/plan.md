# Implementation Plan
## Summary
Добавить документный режим областей, безопасное уточнение строк и обычный шрифт; сравнить старую и новую прямоугольную раскладку. Проверить новые комиксы и устранить подтверждённые локальные регрессии масок без ухудшения принятого набора.
## Technical Context
Python, Pillow, OpenCV, NumPy и имеющийся pyphen. Новых зависимостей нет. Новый src/components/document_layout.py. Пять локальных файлов, VLM по разрешённому LAN endpoint, результаты в output/extended-cases.
## Constitution Check
Pipeline v2; минимальный diff; русские комментарии; локальные данные не коммитятся; качество относится к примерам. Новые настройки, если потребуются, только Config с дефолтами.
## Design
Добавить обратно совместимую отметку document в TextRegion. Определять документную страницу по крупному свободному многострочному блоку на преимущественно однородном фоне; не считать геометрическую прямоугольность облачка достаточной. Уточнять документные боксы по строкам, исключать круглые аватары по геометрии компонент, не сливать обратно строки через отдельные элементы UI. Применять обычный шрифт и левое выравнивание только к документным блокам; ручной стиль важнее. В документе sign с длинным обычным текстом переводится как narration, имена/URL сохраняются.
Прямоугольная раскладка: измерение реальных глифов и обводки, полный текст, отступ, перенос длинных слов, привязка к верху исходного прямоугольника. Переполнение отмечается явно. Сравнить с прежней вёрсткой при одинаковом OCR и переводе.
## Structure
src/models.py — отметка; components/document_layout.py — документные эвристики и раскладка; text_regions.py/vlm_ocr.py/font_catalog.py/text_segmenter.py/typesetter.py — интеграция; tests/unit — регрессии. docs/RECTANGULAR_LAYOUT_RESULTS.md — свидетельства и ограничения.
## Validation
Baseline полный прогон пяти страниц; сравнение геометрии/шрифта/переноса на скриншотах, отдельные сохранённые результаты новых комиксов; проверка принятых трёх масок; целевые тесты, визуальный осмотр, converge.
