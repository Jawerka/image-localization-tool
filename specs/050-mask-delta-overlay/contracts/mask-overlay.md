# UI contract: Маска и цветные ручные назначения

1. Mask grayscale: 0 — вне обработки, 255 — обработка. Негатив чёрный с общей непрозрачностью 50%.
2. paint/fill — #90EE90, erase/erase_fill — #FF9999.
3. Любое ручное назначение получает цвет, даже если бинарное значение не изменилось.
4. Последнее действие определяет цвет; внутри полностью покрытой области alpha всегда 50%.
5. Цвет заменяет чёрное затемнение; исходный grayscale multiply-слой не показывается под композитом.
6. Активная кисть использует тот же композит. Незавершённое лассо — контур/маркеры, без отдельной прозрачной заливки.
7. showMask управляет всей заливкой; курсор и контур могут оставаться видимыми.
8. «Готово» и загрузка PNG не убирают ручные цвета.
9. Повторное открытие восстанавливает цвета из сохранённых strokes.
10. Undo/redo и discard следуют существующему документу, отдельной истории цветов нет.
11. Слой не попадает в result/clean/export и не меняет API документа.
12. Чужая страница/устаревший ответ не допускаются в текущий композит.

## Граница API

`/api/pages/{pageId}/image/mask` продолжает возвращать существующую grayscale маску.
Схема документа, четыре режима Stroke и механизм сохранения остаются прежними.
Новых endpoints нет.

## Пример приёмки

На белом фоне внутри сплошного зелёного следа ожидается примерно RGB(200,247,200), красного — RGB(255,204,204), чёрного — RGB(128,128,128). Допуск 1–2 уровня из-за округления альфы; AA-кромку проверять отдельно. Повторный мазок не меняет эти значения.
