# Data model: Цвет ручных правок

## Существующие данные

`PageDocument.strokes`: упорядоченный список `Stroke`.

- `mode`: paint / erase / fill / erase_fill.
- `radius`: радиус кисти в координатах изображения.
- `points`: координаты точек.

Сериализация, нормализация и серверная обработка сохраняются. Нет новых полей JSON, настроек или файлов проекта.

## Производные данные в памяти

### Базовое представление маски

- Источник: grayscale PNG соответствующей страницы.
- Представление: RGB=0, alpha=255−gray.
- Идентичность: текущий проект/страница, конкретная загруженная картинка, её размер и поколение запроса.
- Недоступный источник: прозрачная база.

### Представление ручных назначений

- Вход: список strokes из актуального документа.
- Цвет: paint/fill → #90EE90; erase/erase_fill → #FF9999.
- Порядок: порядок списка, последняя операция сверху.
- Пустой список/пустые точки: нет следа; полигон менее трёх точек не заливается.
- Геометрия ограничена страницей.

### Активный жест

- Точки и режим из CanvasSession (desktop) / drag (web).
- Рисуется последним, не сериализуется до commit.
- Cancel очищает временную часть.
- Commit переносит в strokes без двойного отображения.

### Кэш

Кэш производный, ограниченный активной страницей для web. Flutter может начать без дополнительного растрового кэша. Инвалидация: смена страницы/проекта, маски, размера или strokes. Панорамирование/выделение не требуют пересчёта исходных пикселей.

## Переходы состояния

```text
загрузка документа → постоянные следы
начало жеста → постоянные следы + временный след
commit → новый список постоянных следов
cancel → прежний список постоянных следов
undo/redo → список соответствующего снимка
discard → список сохранённого документа
Готово → тот же список; позднее новая базовая mask
смена страницы → очистка временного состояния, загрузка новой страницы
```

Постоянство цветов не означает постоянство undo-истории между запусками: история сохраняет существующее поведение.
