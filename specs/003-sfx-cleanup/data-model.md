# Данные

Публичные модели не меняются. Оценщик сохраняет исходный payload анализа, нормализует только автоматические параметры геометрии/стиля перед сравнением и не трогает manual/edited/snapshot. SFX остаётся исходной автоматически полученной ролью, а не назначается по имени файла или эталону.

Артефакты: regions.json, mask.png, clean.png, scoped mask, per-page metrics/warnings, manifest с хешами моделей и исходников. Эталон читается только после автоматической обработки.
