# Quickstart: Page Editor and Typeset

```powershell
venv\Scripts\activate
python -m src.app
```

1. Translate a page; confirm result shows.
2. Draw several brush strokes — no re-layout until «Готово».
3. Press «Готово» — one run; previous result stays visible until the new one appears.
4. Stroke preview while drawing is blue translucent.
