# Implementation Plan: Автоматическая обработка новых страниц
## Summary
Проверить автоматический детектор + RapidOCR, исправить подтверждённые ошибки порядка строк и выборки кропов, затем оценить ретушь и геометрию без ручных координат.
## Technical Context
Python 3.10–3.13, Pillow, NumPy, OpenCV, RapidOCR, ONNX detector, LaMa. Вход PagePipeline v2. Локальные тестовые изображения и результаты не коммитятся.
## Constitution Check
Все пять принципов соблюдены: единый вход v2; малые изменения существующих компонентов; русские комментарии; данные только локально; метрики относятся только к выбранным страницам. Публикация/слияние требуют отдельного разрешения, деплой не производится.
## Project Structure
src/components/rapid_ocr.py — геометрия слов и порядок; src/components/adaptive_text.py и text_segmenter.py — подтверждённые исправления геометрии/ретуши; tests/unit/ — регрессии; docs/ — итог проверки.
## Phase 0: Research
Исследование OCR делегировано отдельному агенту по speckit-plan. Подтверждено: наклонные OCR quad теряют ориентацию при преобразовании в AABB; повторный crop жёстко LTR и может повторно присвоить слова перекрывающегося баллона.
## Phase 1: Design
Сохранить необязательный quad только внутри OcrWord, спроецировать геометрию перед сборкой строк. Передавать направление в crop retry, сохранять единственного владельца слова. Публичная модель TextRegion и HTTP/CLI не меняются.
## Validation
Сравнение автоматических прогонов до/после с фиксированными входами; эталоны открываются только после обработки. Синтетические тесты граничных случаев и существующие тесты OCR/ретуши/вёрстки. Ручные стили не переопределяются.

## Цвет на тёмном фоне и увеличение текста
Новая настройка Config.text_scale по умолчанию 1.1, передаётся в Typesetter и точный preview через AppSettings; участвует в ключе preview-кэша. Автоматическая обводка на фоне с относительной яркостью ниже 0.08 чёрная, заливка белая; custom/none и fill_locked сохраняются. Масштаб применяется один раз после подбора строк вокруг центра текстового блока; raster_fit масштабируется по ширине/высоте. Сохранённые снимки, manual/edited и font_size_override не умножаются. Выход за область отмечается предупреждением и не обрезает текст. Галерея пересобирается по новым изображениям; OCR/перевод не повторяются.

## Уточнение: минимальный кегль
Порог min_font_size применяется в координатах итоговой страницы. Рабочее увеличение умножает порог перед рендером. Аварийная раскладка сохраняет слова при минимуме, свободный растр увеличивается целиком; выход за область помечается переполнением. Старые снимки остаются воспроизводимыми, новая автоматическая генерация использует порог 10.
