# Feature Specification: Ретушь светлых букв на цветных облачках

**Feature Branch**: `codex/008-light-bubble-retouch`
**Created**: 2026-11-04
**Status**: accepted (CLI v2, локальный прогон 2026-11-04)
**Input**: Улучшить ретушь на 3419871.png; для OCR/перевода использовать указанный пользователем LLM.

## User Scenarios & Testing

### User Story 1 — Удалить исходные белые буквы (Priority: P1)

Пользователь переводит страницу с белыми буквами на цветных полупрозрачных облачках. Исходные буквы исчезают, цвет и форма облачков сохраняются.

**Independent Test**: Очистка 3419871.png на фиксированных областях, сравнение с 3419871_mask.png только после очистки.

**Acceptance Scenarios**:
1. Given три найденные надписи, When выполняется очистка, Then удалены все три исходные реплики без заметных остатков.
2. Given цветной градиент и рисунок рядом, When удаляются буквы, Then нет прямоугольных заливок и повреждения границ облачков.

### User Story 2 — Проверить перевод и сохранение прежнего поведения (Priority: P2)

**Independent Test**: Полный прогон с доступным LLM и повторная оценка прежних локальных эталонов.

**Acceptance Scenarios**:
1. Given доступный указанный LLM, When выполняется полный пайплайн, Then результат содержит русский перевод без наложения исходных букв.
2. Given обычные чёрные буквы на белом и белые на тёмном, When применяется исправление, Then покрытие маски не ухудшается более чем на 0.5 п.п. на фиксированном локальном наборе.

### Edge Cases

Белая бумага, светлые рамки и блики не считаются буквами; цветные буквы не удаляются частично как белые; ручные стили сохраняются.

## Requirements

### Functional Requirements

- **FR-001**: Подтверждать белые буквы и на цветном фоне средней светлоты, без обязательной чёрной обводки.
- **FR-002**: Восстанавливать цветной фон, сохраняя края облачка и соседний рисунок.
- **FR-003**: Не использовать эталонную маску для построения автоматической маски.
- **FR-004**: Сохранять существующие публичные входы, настройки и ручные правки.
- **FR-005**: Проверить полный перевод через указанный LLM; сохранить результаты локально, не изменяя постоянные настройки пользователя.

### Key Entities

Исходная страница, существующие текстовые области, маска букв, очищенная страница, перевод.

## Success Criteria

- **SC-001**: Покрытие светлых штрихов на 3419871.png не ниже 99%, spill не выше 2%; визуально нет читаемых исходных букв. Светлые штрихи для этой страницы оцениваются независимо внутри красного эталона: min(R,G,B) ≥ 210, max(R,G,B)−min(R,G,B) < 45. Общая пороговая ink-метрика публикуется отдельно.
- **SC-002**: На прежнем фиксированном наборе нет снижения ink recall более 0.5 п.п.; синтетические проверки бумаги, рамок, цветных букв проходят.
- **SC-003**: Получен и осмотрен результат полного автоматического перевода на русский; ограничения размещения явно записаны.

## Assumptions

Это исправление относительно 001 и существующих улучшений 002–007. Эталон и все пользовательские изображения остаются локальными. Качество на произвольных страницах не заявляется. Публикация, PR и слияние требуют отдельной авторизации.

## Приёмка и уточнение оценки

При исследовании выяснилось, что исходная общая ink-метрика включает тёмную половину градиента облачка в чернила; residue тоже штрафует сохранённый градиент. Поэтому до приёмки SC-001 уточнён для реально белого текста; это отдельная оценка, а не переименование общей метрики. Порог не используется при очистке из эталона.

Полный прогон с указанным LLM: три реплики распознаны и переведены, переполнения нет. Светлые штрихи: 43.16% → 100% (3445 пикселей). Общая ink-метрика: 31.83% → 91.68%; spill 0.02%. На 20 прежних фиксированных страницах нет падения покрытия; 16 масок идентичны, максимальный рост spill 0.56 п.п. Цифры относятся к этим страницам.

На увеличении остаются слабые неровности восстановленного градиента. Мелкое чёрное оформление перевода с белой обводкой не изменялось. Проверки: 89 релевантных тестов и дополнительный интеграционный тест сглаживания/ручного исключения; все прошли. Локальные доказательства: output/3419871-check/verification.json, final/, regression-verified.json, tests.log.
