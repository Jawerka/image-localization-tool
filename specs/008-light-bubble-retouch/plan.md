# Implementation Plan: Ретушь светлых букв
**Branch**: codex/008-light-bubble-retouch | **Date**: 2026-11-04 | **Spec**: [spec.md](spec.md)

## Summary
Расширить существующее подтверждение белых букв на цветной фон средней светлоты по локальному контрасту отдельных компонент. Сохранить отбраковку крупных полей и краевых объектов. Эталоны доступны только оценщику.

## Technical Context
Python 3.10–3.13, NumPy, OpenCV, PIL, существующий LaMa и LLM-клиент. Новых зависимостей, настроек и публичных контрактов нет. Проверки: pytest, фиксированные маски прежних локальных страниц, полный прогон 3419871 через LLM.

## Constitution Check
До и после проектирования: v2 сохранён; минимальный diff в существующих компонентах; комментарии русские; локальные данные игнорируются; выводы ограничены проверенным набором. Отдельная ветка. PR/слияние вне авторизации. Нарушений нет.

## Project Structure
src/components/retouch_ink.py: локальное подтверждение светлых букв.
src/components/text_segmenter.py, adaptive_text.py: интеграция и исходный цвет при необходимости.
tests/unit/test_retouch_ink.py: проверки цветных фонов и ложных компонент.
docs/BENCHMARK_RESULTS.md: результаты и ограничения.
output/3419871-check/: локальные артефакты, не коммитить.

src/page_pipeline.py: убрать тонкие выдуманные LaMa детали медианным фильтром только внутри маски подтверждённого гладкого фона; ручные исключения и отредактированные регионы защищены.
tests/integration/test_page_pipeline.py: проверить сглаживание с ручным исключением и сохранением всех пикселей вне маски.

## Complexity Tracking
Новый движок не создаётся. Прежняя сегментация и LaMa сохраняются.
