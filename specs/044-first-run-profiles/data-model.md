# Data Model: Профили первого запуска

Новых постоянных сущностей нет. Используются существующие настройки и coordinator состояния.

## Профиль мастера

- `profile`: выбор UI `llm` или `offline`; по умолчанию — `llm` для уже настроенного backend, иначе сохраняется полный локальный fallback.
- `source_lang`, `target_lang`: параметры плана компонентов.
- `translator_backend`: `llm` для server LLM/VLM либо `argos` для offline сценария.
- `inpainter`, `device`, `models_dir`: существующие параметры подготовки и расположения.

## План подготовки

Получается от существующего API и включает список компонентов, download bytes, required disk space и предупреждения. UI не хранит отдельную копию серверного реестра.

## Состояние подготовки

Coordinator предоставляет фазу, прогресс, текущий компонент, ошибки и поддержку pause/resume. Текущая работа сопоставляется с параметрами профиля перед продолжением.

## Ограничения

- Неподдерживаемая offline language pair является ошибкой плана и не должна менять сохранённую конфигурацию.
- API ключ не записывается в JSON/отчёт.
- Успешный план с 0 байт не запускает пустую загрузку.
