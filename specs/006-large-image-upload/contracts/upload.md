# Контракт LAN-загрузки

GET /v1/health сохраняет version и ready и добавляет max_body_bytes: 67108864. Старый ответ совместим; клиент использует 20971520 при отсутствующем/некорректном лимите.
POST /v1/translate сохраняет multipart/form-data и авторизацию. Content-Type содержит boundary сериализованного Blob. Тело <= max_body_bytes принимается при остальных пройденных проверках; превышение даёт 413. Ограничение 40 000 000 пикселей остаётся.
Клиент до POST проверяет точный размер; превышение — E_UPLOAD_SIZE и сообщение с лимитом. HTTP 413 — текст error из JSON либо понятный отказ по размеру, код E_HTTP_413. Сетевой отказ — E_NETWORK. Сетевой сбой POST не повторяется автоматически.
