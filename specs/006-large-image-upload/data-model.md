# Модель данных

Нового постоянного хранения нет.
- Health: version, ready (существующие); max_body_bytes — положительное безопасное целое, потолок тела запроса в байтах. При отсутствии или некорректном значении клиент использует 20×1024×1024.
- Подготовленная загрузка: Blob multipart с исходным файлом, языком и fresh. Размер сравнивается с потолком; равенство разрешено.
- Ошибка клиента: message и code (E_UPLOAD_SIZE, E_HTTP_413, E_NETWORK); состояние задания error сохраняет code. HTTP-журнал: путь и метод, status, код; без тела и Authorization.
