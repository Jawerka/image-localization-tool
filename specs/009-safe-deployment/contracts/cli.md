# Контракты CLI

deploy-lan.ps1 сохраняет Hosts/User/ProxyJump/RemoteRoot/Service/IncludeTests, DryRun теперь проверяет реальный сервер; добавлен Report для JSON-отчёта. Обычный запуск всегда начинает с такого же dry run и повторно проверяет хеши перед записью.

deploy-windows.ps1 сохраняет Dest/Build/IncludeModels, добавлен DryRun. Build вместе с DryRun отклоняется: сначала собрать артефакты, затем проверять реальный пакет. IncludeModels больше не удаляет отсутствующие в пакете модели.

Dry run не записывает файлы установки, не загружает архив на сервер, не создаёт backup и не перезапускает службу. Локальный отчёт при явном Report допустим.
