# Модель данных

Манифест: относительный путь кода, размер, SHA256. План: исходные хеши на сервере, список изменений, цель/служба и оценка места. Результат: backup path, изменённые файлы и health_ready. Пользовательские файлы не включаются в манифест, сохраняются отдельной резервной копией на целевом хосте.
