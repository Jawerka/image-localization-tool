# Feature Specification: Читаемый текст в облачках
**Feature Branch**: `codex/034-readable-balloon-layout`
**Created**: 2026-10-18
**Status**: Approved for implementation by user request
**Input**: Закрепить удачный вариант масок и попробовать способы крупного заполнения облачков текстом.

## User Scenarios & Testing
### User Story 1 — Сохранение качественной очистки (Priority: P1)
Пользователь получает результат принятого эксперимента при обычной обработке.
**Why this priority**: Пользователь одобрил визуальный результат.
**Independent Test**: Сопоставление масок трёх локальных страниц с принятым экспериментом.
**Acceptance Scenarios**: При прежних регионах маска облачков совпадает с принятым вариантом; пустой или некорректный регион не вызывает сбоя.
### User Story 2 — Крупный текст внутри облачка (Priority: P1)
Пользователь читает реплики без неоправданно мелкого шрифта.
**Why this priority**: На 0001 справа большая область занята мелкой строкой.
**Independent Test**: Сравнение нескольких способов заполнения на одинаковых текстах и очищенных страницах.
**Acceptance Scenarios**: Текст переносится по форме облачка, сохраняется полностью, помещается с отступом; ручной размер шрифта сохраняет приоритет; невозможность размещения отмечается.
### Edge Cases
Короткая реплика, длинное слово, тёмный фон, хвост облачка, несколько компонент, пустая маска, ручные настройки, SFX и текст вне облачков.

## Requirements
### Functional Requirements
- **FR-001**: Использовать одобренные маски в обычном пайплайне.
- **FR-002**: Подбирать крупный помещающийся текст с переносами по форме облачка без потери слов.
- **FR-003**: Не считать обрезанный или вышедший за область текст успешным размещением.
- **FR-004**: Сохранить ручные настройки, обработку SFX и документов.
- **FR-005**: Сравнить минимум три варианта расчёта заполнения на трёх предоставленных страницах и сохранить изображения и численные результаты.
### Key Entities
Область облачка, безопасная область размещения, текст реплики, ручные настройки, результат сравнения.

## Success Criteria
### Measurable Outcomes
- **SC-001**: Маски облачков на трёх страницах совпадают с одобренным экспериментом.
- **SC-002**: Проблемная реплика справа на 0001 получает шрифт минимум в 1.5 раза крупнее исходного при сохранении всех слов.
- **SC-003**: Автоматически размещённые строки на трёх страницах полностью помещаются в рассчитанную безопасную область; неприменимые случаи явно отмечаются.
- **SC-004**: Сохранены сравнения минимум трёх способов и пройдены целевые регрессионные проверки.

## Assumptions
Заполнение означает крупный читаемый текст с небольшим запасом до края; искусственное растягивание букв и заполнение хвостов не требуется. Переносы слов разрешены по языковому словарю. Публикация, сборка exe и деплой в запрос не входят. Локальные изображения не включаются в git. Результаты на этих страницах не гарантируют качества на произвольном комиксе.
