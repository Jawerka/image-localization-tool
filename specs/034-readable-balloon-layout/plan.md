# Implementation Plan: Читаемые облачка
## Summary
Перенести проверенные seed85/multi56 маски в bubble_contour. Сравнить прежнюю вёрстку, новую геометрию со старым переносом и раскладку по полосам формы с поиском разбиения строк. Выбрать по визуальному результату, кеглю, целостности текста и размещению внутри формы.
## Technical Context
Python, Pillow, NumPy, OpenCV, существующий pyphen. Новых зависимостей нет. Новый алгоритм раскладки — отдельный src/components/bubble_layout.py. Исходные точки входа и JSON не меняются.
## Constitution Check
Все пять принципов соблюдены: pipeline v2; ограниченный diff; русские комментарии; локальные артефакты в output; ограниченные заявления о качестве. Проверить повторно после реализации.
## Project Structure
src/components/bubble_contour.py — маска; bubble_layout.py — раскладка; typesetter.py — интеграция; tests/unit — регрессии; scripts/eval_balloon_layout.py — воспроизводимое сравнение; docs — результат.
## Research
Причины мелкого текста: отдельная flood-fill геометрия после ретуши, обрыв области, жадный перенос по ширине средней строки. Нужна геометрия на основе принятого выделения облачка и поиск разбиений по фактической ширине каждой полосы. Подробности в research.md.
## Design
Не менять модель сохранения. Никакой скрытой истории региона; геометрия пересчитывается из доступного изображения. Для обычных облачков новый перенос; документы, SFX и сложные ручные преобразования сохраняют прежнюю ветку. Учитывать реальные границы глифов, обводку и межстрочный интервал. Неудачное размещение возвращает overflow.
## Validation
Тесты до реализации, сравнение масок с принятым прототипом, три способа на трёх страницах без повторного OCR, визуальный осмотр и целевые unit/regression тесты. Не обещать обобщение за пределы набора.
