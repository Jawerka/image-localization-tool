# Layout Contract
free_raster возвращает RGBA и снимок; вертикальный текст сохраняет оригинальную строку и метаданные режима. Один и тот же снимок используется предпросмотром и экспортом. Ручные font_id, edited/manual, override и rotation важнее автоматического изменения. Новый шрифт берётся из каталога; при отсутствии — прежний доступный fallback. Никаких изменений API входов.
