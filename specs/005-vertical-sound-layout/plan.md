# Implementation Plan: Тонкие звуки и вертикальное письмо
**Branch**: 005-vertical-sound-layout | **Date**: 2026-11-03 | **Spec**: [spec.md](spec.md)
## Summary
Встроенный Jupiteroid Light для свободных звуков, без внутреннего утолщения; контрастная внешняя обводка сохраняется. Прямые буквы сверху вниз в общем free_raster с сохранением снимка. Консервативная геометрия непривязанной речи и адресные исправления выявленных дефектов.
## Technical Context
Python 3.10–3.13, Pillow/OpenCV/NumPy; pytest. Общий пайплайн v2 на всех поверхностях. Старые JSON совместимы. Сохраняются ручные правки. 28 локальных страниц, без новых сетевых зависимостей.
## Constitution Check
Принципы I–V соблюдены: пайплайн v2, минимальные изменения существующих компонентов, русские комментарии, локальные данные не коммитятся, результаты ограничены локальным набором. После design проверено повторно. Новых пользовательских настроек нет, API входов прежний. PR/merge/deploy этим запросом не разрешены.
## Project Structure
src/components/free_text_layout.py, glyph_layout.py, font_catalog.py, adaptive_text.py; src/models.py только валидация необязательных метаданных. tests/unit/test_vertical_sound_layout.py; docs/FONTS.md; specs/005-vertical-sound-layout.
## Phase 0 — Research
Сравнение встроенных шрифтов выполнено; исследовательский агент просмотрел проблемные страницы 12/20/21/23, подтвердил ошибочный контур r23/8 и неполное покрытие SFX r20/15,17. Подробности и ограничения фиксируются в validation.md.
## Phase 1 — Design
writing_mode=vertical — явный сохранённый режим; auto выбирает только короткий высокий SFX, по выигрышу размера букв. Буквы размещаются по фактическим bbox в равных ячейках; пробел даёт промежуток. Snapshot хранит режим и исходный текст. Внешняя белая обводка остаётся и резервируется в подгонке. Горизонтальные свободные надписи используют прежнюю геометрию. Ложная привязка к белому фону отклоняется по геометрии исходника.
## Validation
Тесты порядка букв/пробелов/сохранения/ручного выбора/обводки. Повторный рендер 28 сохранённых страниц и визуальный просмотр известных проблем. Предупреждения не скрывать; недоказанные OCR-исправления явно указывать.
