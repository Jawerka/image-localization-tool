# Implementation Plan: Наведение и качество страниц
**Branch**: `014-hover-page-quality` | **Date**: 2026-11-09 | **Spec**: [spec.md](spec.md)
## Summary
Ограничить hit testing верхним элементом страницы, повторять проверку перед показом и при изменениях перекрытия. Исправления качества выбирать по автономному baseline двух страниц и контрольной выборке.
## Technical Context
JavaScript расширения Chromium, Python 3.10–3.13; существующие PagePipeline, ONNX, VLM, LaMa. Проверки: pytest/Playwright, node:test, полные локальные прогоны. Данные и артефакты только в игнорируемом output; никаких новых настроек или API. Не выполнять параллельные LLM-запросы.
## Constitution Check
Все пять принципов соблюдены: v2, минимальный diff, русский язык комментариев, локальные данные, ограниченные утверждения о качестве. Отдельная ветка создана. Публикация и слияние требуют отдельного разрешения и не входят в реализацию. Повторная проверка дизайна: исключений нет.
## Project Structure
extension/src/safe-content.js, extension/src/inline-content.js — наведение.
src/components/ и src/page_pipeline.py — только подтверждённые общие исправления обработки.
tests/e2e/test_extension_safe.py — popup и задержка; tests/unit/ — подтверждённые регрессии обработки.
docs/BENCHMARK_RESULTS.md — результаты и ограничения.
## Validation
Baseline без эталонных масок на входе. Эталоны только в метриках после обработки. Повторить две новые страницы и минимум три старые страницы; визуально проверить очистку и вёрстку. Не подменять визуальное качество ink recall.

## Дополнение: вычитка перевода
Подтверждённые в автономном прогоне ошибки согласования требуют отдельного редакторского запроса, а не одной инструкции внутри первоначального перевода. `LlmTranslator.proofread` получает только машинные исходники/черновики и общий контекст в порядке чтения. `PagePipeline` вызывает его после полного и одиночного перевода. Запрос выполняется последовательно; формат регионов и настройки не меняются. Неполный/ошибочный ответ не уничтожает черновик и не включает Argos поверх успешного перевода. Ручные переводы и посторонние id защищены. Проверки — tests/unit/test_llm_translator.py и tests/integration/test_page_pipeline.py; целевая приёмка — автономная вычитка пяти контрольных страниц без готовых исправлений в промпте.
