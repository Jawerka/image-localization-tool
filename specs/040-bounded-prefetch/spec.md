# Feature Specification: Ограниченная предварительная загрузка

**Feature Branch**: `[codex/036-inspector-redesign]`  
**Created**: 2026-10-18  
**Status**: Implemented
**Input**: T20 из `tasks/todo.md`: ограничить параллельную загрузку файлов подготовки; сохранить pause/resume, integrity checks и последовательную установку.

## User Scenarios & Testing

### User Story 1 — Быстрее скачать независимые файлы (Priority: P1)

Пользователь запускает подготовку моделей. Независимые файлы скачиваются параллельно с небольшим настраиваемым лимитом, а установка компонентов по-прежнему происходит по одному.

**Independent Test**: локальный HTTP-сервер считает одновременные запросы; подготовка загружает несколько файлов, не превышая заданный лимит, и устанавливает компоненты последовательно.

**Acceptance Scenarios**:

1. **Given** в плане есть несколько незагруженных файлов, **When** подготовка начинается, **Then** одновременно скачивается не больше заданного числа файлов.
2. **Given** все файлы скачаны и проверены, **When** начинается установка, **Then** установка и активация идут последовательно.

### User Story 2 — Продолжить после паузы или сбоя (Priority: P1)

Пользователь приостанавливает подготовку или сталкивается с обрывом сети. Повторный запуск продолжает докачку сохранённых частей, проверяет размер и SHA-256 и не активирует неполный компонент.

**Independent Test**: локальный сервер прерывает передачу или подготовка ставится на паузу; после продолжения загружаются только недостающие байты и компоненты активируются после успешной проверки.

**Acceptance Scenarios**:

1. **Given** активная загрузка, **When** пользователь ставит её на паузу, **Then** новые файлы перестают начинать загрузку, частичные файлы остаются пригодны для продолжения.
2. **Given** файл имеет неверный размер или SHA-256, **When** подготовка возобновляется, **Then** такой файл не устанавливается и ошибка отражается в статусе.

## Edge Cases

- Один и тот же SHA-256 указан несколькими компонентами — файл загружается один раз.
- В очереди нет недостающих файлов — предварительная загрузка завершается без сетевых запросов.
- Лимит задан меньше единицы или чрезмерно высок — используется безопасное ограниченное значение.
- Один файл завершился ошибкой во время других загрузок — установка не начинается; уже проверенные кэш-файлы сохраняются.
- Пользователь ставит подготовку на паузу во время повторной попытки — ожидание прерывается и очередь остаётся в состоянии паузы.

## Requirements

### Functional Requirements

- **FR-001**: Система MUST скачивать независимые файлы подготовки с ограниченным числом одновременных загрузок.
- **FR-002**: Лимит MUST задаваться настройкой с безопасным значением по умолчанию и жёсткой верхней границей.
- **FR-003**: Система MUST пропускать уже проверенные кэш-файлы и объединять одинаковые файлы по SHA-256.
- **FR-004**: Каждый файл MUST проходить существующую проверку размера и SHA-256 до установки.
- **FR-005**: Pause/resume MUST сохранять частичный прогресс и продолжать загрузку через существующий Range/If-Range механизм.
- **FR-006**: Установка, проверки компонентов и активация MUST оставаться последовательными.
- **FR-007**: При ошибке предварительной загрузки установка компонентов не начинается; очередь сообщает ошибку и сохраняет проверенный кэш.

## Success Criteria

### Measurable Outcomes

- **SC-001**: В тесте с несколькими файлами наблюдаемая конкурентность никогда не превышает настроенный лимит.
- **SC-002**: На фикстурах с минимум тремя файлами измеряется более одного одновременного запроса при лимите выше единицы.
- **SC-003**: После паузы/обрыва загрузки все итоговые файлы совпадают с эталонными SHA-256.
- **SC-004**: Порядок установки и активации остаётся последовательным независимо от порядка завершения загрузок.

## Assumptions

- Источники каталогов независимы, когда файлы имеют разные SHA-256.
- Конкурентность применяется только к передаче файлов; unpack, проверки, установка и переключение active marker остаются последовательными.
- Существующий файловый кэш и межпроцессные locks остаются источником целостности.
