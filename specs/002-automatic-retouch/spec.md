# Feature Specification: Автоматическая разметка для ретуши

**Feature Branch**: `codex/002-automatic-retouch`
**Created**: 2026-11-01
**Status**: Implemented — локальная приёмка этапа очистки; установленные поверхности не обновлялись
**Input**: Приблизить автоматическую ретушь к результату с пользовательской разметкой, ориентир — 95% от него, с контролем регрессий на остальных локальных изображениях.

## User Scenarios & Testing

### User Story 1 — Удаление сложного текста (Priority: P1)

Пользователь запускает обычную обработку страницы и получает чистый фон без необходимости вручную закрашивать каждую букву.

**Why this priority**: Текущая маска пропускает белые буквы в тёмных плашках и части обведённого текста.
**Independent Test**: Автоматически найти регионы и очистить три целевые страницы без чтения эталонной разметки алгоритмом.
**Acceptance Scenarios**:
1. На цветной странице обведённые буквы удаляются целиком, включая начальные буквы строк.
2. На 01-- белые иероглифы удаляются из обеих тёмных плашек, просвечивающие линии и границы плашек сохраняются.
3. На 3923336 белые баллоны остаются чистыми, контуры и рисунок не приобретают новых дефектов относительно исходного алгоритма.

### User Story 2 — Контроль регрессий (Priority: P1)

Разработчик повторяет сравнение до/после на локальных парах и видит ухудшения по каждой странице.

**Why this priority**: Улучшение нескольких примеров не оправдывает ухудшение уже работающих страниц.
**Independent Test**: Один воспроизводимый прогон использует одинаковые найденные регионы для старой и новой очистки, сохраняет маски, чистые страницы и показатели.
**Acceptance Scenarios**:
1. Все доступные пары проверяются, включая sound-ref; регрессии показываются по отдельности, а не скрываются средним.
2. Эталонные маски используются только оценщиком, не автоматическим алгоритмом.
3. Отсутствующая модель или фолбэк явно отражаются в отчёте.

### Edge Cases

Белые и чёрные буквы, противоположная обводка, вертикальные строки, текст возле контура, прозрачные плашки, градиент, скринтон, перекрывающиеся регионы, ручное вычитание маски, SFX skip, пустая маска, отсутствие LaMa.

## Requirements

### Functional Requirements

- **FR-001**: Автоматическое выделение должно учитывать обе полярности букв и обводки без ручной разметки и без зависимости от имени файла.
- **FR-002**: Очистка должна сохранять видимый рисунок внутри прозрачных плашек и не принимать их за однотонный баллон.
- **FR-003**: Полностью закрытые маской буквы не должны возвращаться при смешивании результата с оригиналом.
- **FR-004**: Ручные штрихи и исключённые из перевода регионы сохраняют существующий смысл; интерфейсы приложения не меняются.
- **FR-005**: Должны существовать повторяемые сравнения всех доступных локальных эталонных пар с сохранением результатов до/после и предупреждений; новые дефекты оцениваются отдельно от покрытия текста.
- **FR-006**: Все пути обработки продолжают пользоваться пайплайном v2; новые модели, сетевые сервисы и пользовательские настройки для этой доработки не требуются.

### Key Entities

- Автоматическая маска: области полного удаления текста, построенные только по изображению и найденным регионам.
- Эталонная зона текста: локальная разметка для оценки; не является эталоном скрытого рисунка.
- Результат сравнения: параметры прогона, показатели по каждой странице, изображения и предупреждения.

## Success Criteria

### Measurable Outcomes

- **SC-001**: На трёх целевых страницах покрывается не менее 99% диагностически выделенных чернил; визуальная проверка отдельно подтверждает отсутствие читаемых слов в целевых регионах. Покрытие не объявляется процентом качества ретуши.
- **SC-002**: Для сложных целевых страниц сравнение с очисткой по пользовательской разметке сохраняет не менее 95% её улучшения по диагностическому остаточному контрасту относительно оригинала, без новых заметных повреждений границ/рисунка. Если показатель не определён или противоречит визуальной оценке, результат не считается автоматически принятым.
- **SC-003**: На остальных локальных эталонах нет потери покрытия более 0.5 процентного пункта и нет новых заметных повреждений рисунка; отклонения в остатках/порче показываются отдельно и исследуются до приёмки.
- **SC-004**: Фиксированные синтетические проверки обеих полярностей, защиты контура, смешивания и ручных исключений проходят без моделей; реальные результаты дополнительно проверяются с LaMa.

## Assumptions

- «95%» — ориентир близости к контрольной очистке на данных страницах, не обещание качества на произвольном изображении. Разметка не содержит истинного изображения без текста.
- OCR и перевод могут оцениваться отдельно: основной сравнительный прогон фиксирует регионы и непустые тексты, чтобы измерять изменение очистки, а не случайность распознавания.
- Изменения интерфейса, деплой и массовое удаление подписей/логотипов вне области задачи.
