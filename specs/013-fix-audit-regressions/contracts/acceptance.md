# Contracts
Transport: finite headers/body/error-body operations; errors distinguish stage; logs omit secrets and URL query; ambiguous POST never automatically retried.
Panel: all actions reachable at 320px; actual geometry follows image; expanded surfaces do not overlap.
OCR: failed crop exposes warning/fallback or failure; no silent empty success.
Intake: each distinct relative source name has separate output/UI identity; summary records failures; exit 0 success, 1 partial, 2 all failed.
Deploy: prepare writes only artifact; dry run does not write target; apply consumes exact plan; preconditions and backup checked before mutation; rollback verifies originals and preserves unmanaged files.
