# Research
- A01/A02: ограничивать headers + body единым abort/race; хранить абсолютный срок задания с учётом очереди и восстановления worker. POST не повторять при неопределённом исходе.
- A06–A08: перенос строк и измерение фактической панели; единый активный раскрытый слой предотвращает конфликт ошибки; geometry watcher нужен для transform без resize.
- A09: сериализовать полный referer fallback, включая тело и finally, иначе один DNR id обслуживает два запроса ошибочно.
- A03: неизменяемая подготовленная сборка, план с хешами исходного состояния и артефакта, backup до записи, управляемые обратные операции без зеркального удаления.
- A10/A11: идентичность по полному относительному имени; отдельный итог success/partial/failure и коды 0/1/2.
- A04: не превращать отказ crop в пустой успешный OCR; действующий прежний текст можно сохранить только с предупреждением.
- A14: ограниченные перекрывающиеся фрагменты с переносом координат и проверкой локального текста; generic prompt уже включает SFX, причина не в отсутствии этого слова.
- A15: оценивать угол по согласованным штрихам строк, исключая соседний крупный звук и лучи, без порогов под конкретное изображение.
- A05/A12/A13: воспроизводить маски отдельно при одинаковом автоматическом OCR; не откатывать целиком полезную цветную сегментацию.
Альтернативы отклонены: повтор POST, общий беззащитный DNR id, /MIR, группировка по stem, ручные рамки/маски и имена страниц в алгоритме.
