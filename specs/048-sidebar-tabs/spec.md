## User Scenarios & Testing

### User Story 1 — Переключение страниц и очереди (Priority: P1)

Как пользователь редактора, я хочу видеть слева две вкладки «Страницы» и «Очередь», чтобы переключаться между выбором страниц и ходом пакетной обработки.

**Why this priority**: Это основная цель изменения левой панели.

**Independent Test**: Открыть проект и по очереди выбрать обе вкладки; каждая показывает свой список и не меняет открытую страницу.

**Acceptance Scenarios**:

1. **Given** проект со страницами, **When** пользователь выбирает «Страницы», **Then** показывается список страниц и счётчик готовности.
2. **Given** проект со страницами, **When** пользователь выбирает «Очередь», **Then** показывается прогресс пакетной обработки, статусы страниц, фильтры и доступные действия очереди.
3. **Given** очередь выполняется, **When** пользователь переключает вкладки, **Then** обработка и её обновления продолжаются, а вкладка очереди показывает актуальное состояние.
4. **Given** пользователь переключает вкладки, **When** он возвращается к «Страницам», **Then** выбранная страница и её состояние сохраняются.
5. **Given** узкая или широкая левая панель, **When** пользователь переключает вкладки, **Then** вкладки остаются доступны с клавиатуры и указателя.

### Edge Cases

- Если проект пуст, вкладка «Очередь» показывает существующее пустое состояние, а «Страницы» — отсутствие страниц.
- Если пакетная обработка не запущена, вкладка «Очередь» показывает сводку и предлагает открыть папку главы согласно текущему сценарию.
- При свёрнутой левой панели переключатель вкладок скрыт вместе с содержимым панели.

## Requirements

### Functional Requirements

- **FR-001**: Левая панель MUST иметь ровно две вкладки с подписями «Страницы» и «Очередь».
- **FR-002**: «Страницы» MUST показывать текущий список страниц, выбор, перетаскивание порядка, контекстные действия и счётчик готовности.
- **FR-003**: «Очередь» MUST показывать существующий пакетный обзор с ходом обработки, списком статусов страниц, фильтрами и действиями.
- **FR-004**: Переключение вкладок MUST менять только видимость панелей и не сбрасывать выбранную страницу, прогресс, фильтры или работу очереди.
- **FR-005**: Вкладки MUST быть доступны мышью и клавиатурой, объявлять выбранную вкладку и связь с панелью для вспомогательных технологий.
- **FR-006**: Существующее сворачивание левой панели MUST продолжать работать.

### Key Entities

- **Вкладка панели**: выбранный раздел левой панели — страницы или очередь.
- **Состояние очереди**: уже существующие страницы, статусы, прогресс и доступные действия пакетной обработки.

## Success Criteria

### Measurable Outcomes

- **SC-001**: Пользователь может перейти от списка страниц к очереди и обратно одним нажатием.
- **SC-002**: После перехода между вкладками текущая страница, статусы и прогресс очереди остаются без изменений.
- **SC-003**: Обе вкладки корректно управляются клавишами со стрелками, Home, End, Enter и пробелом.

## Assumptions

- Пакетный обзор и очередь уже реализованы; фича перемещает их в отдельную вкладку без изменения логики обработки.
- По умолчанию при открытии приложения выбрана вкладка «Страницы».
- Вкладка не меняет существующее состояние обработки и не добавляет новые настройки.
