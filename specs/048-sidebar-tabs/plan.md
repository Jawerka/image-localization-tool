# Implementation Plan: Вкладки списка страниц и очереди

**Branch**: `048-sidebar-tabs` | **Date**: 2026-10-19 | **Spec**: [spec.md](spec.md)

## Summary

Разделить левую панель редактора на вкладки «Страницы» и «Очередь». Список страниц останется в первой вкладке, существующий пакетный обзор `batch-panel.js` переместится во вторую. Состояние страниц и фоновой обработки продолжит поступать из общего state и не будет зависеть от видимости вкладки.

## Technical Context

**Language/Version**: JavaScript ES modules, HTML, CSS
**Primary Dependencies**: DOM API, существующий `batch-panel.js`
**Storage**: Память текущей страницы приложения; новое постоянное хранилище не требуется
**Testing**: Ручная проверка состояний редактора и доступности вкладок
**Target Platform**: WebView2 desktop host и поддерживаемые браузеры
**Project Type**: Desktop app with embedded web UI
**Performance Goals**: Переключение вкладки не перезапускает рендер пайплайна и не влияет на фоновую очередь
**Constraints**: Минимальный diff; сохранить текущие действия страницы/очереди; доступность мышью и клавиатурой
**Scale/Scope**: Левая панель `web/index.html`, её стили и инициализация клиентского UI

## Constitution Check

- Пайплайн обработки не меняется.
- Изменение ограничено существующим веб-интерфейсом и не добавляет движки или настройки.
- Комментарии и docstring — на русском.
- HTTP API и формат документа не меняются.

## Implementation

1. Заменить статический заголовок левой панели на вкладки и разделить существующие страницы и batch-panel по отдельным панелям.
2. Добавить небольшой модуль переключения с ARIA-состояниями и клавиатурными стрелками; выбранная страница и очередь остаются в общем состоянии приложения.
3. Переместить отрисовку batch-panel в панель очереди и оформить вертикальный scroll без дублирования списка на вкладке страниц.
