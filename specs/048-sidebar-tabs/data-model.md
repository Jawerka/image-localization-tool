# Data Model: Вкладки списка страниц и очереди

Новые серверные сущности и формат сохраняемых проектов не добавляются.

## Состояние вкладок

- `selectedTab`: локальный идентификатор `pages` или `queue`.
- Начальное значение: `pages`.
- Изменение значения обновляет выбранную вкладку и видимую панель.
- Выбор страницы, список страниц, статусы и прогресс пакетной обработки принадлежат существующему состоянию приложения и не меняются при переключении.
