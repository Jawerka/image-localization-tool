# Feature Specification: Качество распознавания новых страниц
**Feature Branch**: `codex/017-recognition-quality`
**Created**: 2026-11-14
**Status**: Implemented with open quality gaps (see convergence.md)
**Input**: Шесть новых пар из test-img и выборочная регрессия; изменение относительно 001.

## User Scenarios & Testing
### User Story 1 — Полнота распознавания (P1)
Пользователь обрабатывает новые страницы без ручной геометрии.
**Independent Test**: свежий проход шести страниц; сравнение текста и покрытия разметки.
**Acceptance Scenarios**: каждая размеченная реплика найдена; пропуски и лишние области перечислены отдельно.
### User Story 2 — Сохранение качества (P2)
**Independent Test**: повторная проверка старых страниц с тёмным, светлым и наклонным текстом.
**Acceptance Scenarios**: результаты до/после сопоставлены при одинаковых настройках.
### Edge Cases
Мелкие буквы, светлый текст с контуром, крупные наклонные звуки, несколько реплик внутри одной детекции; недоступный сервер LLM.

## Requirements
- **FR-001**: Проверить все шесть пар; маски используются только для оценки, не как вход распознавания.
- **FR-002**: Исправлять общие причины пропусков без привязки к именам страниц.
- **FR-003**: Сохранить исходные и итоговые результаты и явно указать оставшиеся дефекты.
- **FR-004**: Выполнить выборочную регрессию и профильные тесты.
- **FR-005**: При финальной отрисовке сохранять подтверждённую пару цвета исходных букв и контрастной обводки; ручные цвета и режимы обводки имеют приоритет.
### Key Entities
Страница, эталон областей, автоматически найденные регионы, распознанные строки, отчёт сравнения.

## Success Criteria
- **SC-001**: Проверены 6 из 6 новых страниц, все размеченные реплики учтены в отчёте.
- **SC-002**: Цель покрытия выделяемых букв — не ниже 99.8%; недостижение явно отражено по странице.
- **SC-003**: На выбранных старых страницах нет новых пропусков; выполненные проверки и ограничения записаны.

## Assumptions
Красные маски — эталоны областей, не транскрипции и не точные маски букв. Полное качество OCR требует визуального чтения; без эталонной транскрипции CER не заявляется. Деплой не входит в задачу.
