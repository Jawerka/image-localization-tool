# Feature Specification: Локальный предпросмотр mesh-деформации

**Feature Branch**: `codex/036-inspector-redesign`  
**Created**: 2026-10-18  
**Status**: Draft  
**Input**: Во время редактирования mesh пользователь должен видеть деформацию без ожидания полного серверного preview; после жеста результат должен совпасть с экспортом.

## User Scenarios & Testing

### User Story 1 — Черновой preview mesh (Priority: P1)
Пользователь перетаскивает узел 4×4 mesh и видит деформированный текст на очищенной странице в том же жесте.

**Independent Test**: На прозрачном слое с кириллицей и обводкой сравнить неподвижный кадр, изменённый кадр и alpha; проверить отклик p95 ≤33 мс в согласованном WebView2.

### User Story 2 — Точный результат после жеста (Priority: P1)
После отпускания указателя приложение запрашивает точный Typesetter preview. Ответ применяется только к тому же проекту, странице, региону и revision.

**Independent Test**: Задержать ответы двух preview и вернуть их в обратном порядке; видимым должен остаться последний revision. Сравнить final preview с экспортом при зафиксированных данных.

### User Story 3 — Ошибка GPU или неверная геометрия (Priority: P2)
При потере WebGL-контекста либо вырожденной mesh-ячеейке приложение объясняет причину и сохраняет текущую точную серверную отрисовку.

**Independent Test**: Отвергнуть invalid mesh до commit и принудительно потерять WebGL-контекст; документ и точный preview остаются доступны.

## Functional Requirements

- **FR-001**: Базовая прозрачная RGBA-текстура создаётся один раз для исходного текста, оформления и размеров текущей revision.
- **FR-002**: Черновые кадры используют ту же исходную текстуру; пиксели предыдущего деформированного кадра никогда не становятся источником следующего.
- **FR-003**: JS и Python используют версионированный mesh contract и одинаковый порядок геометрических преобразований.
- **FR-004**: Серверный preview остаётся точным источником результата после завершения жеста.
- **FR-005**: Устаревший exact preview не может заменить более новый черновик или регион.
- **FR-006**: WebGL — необязательное ускорение; ошибка контекста отключает локальный renderer и не повреждает документ.
- **FR-007**: Валидация mesh блокирует вырожденные и перевёрнутые ячейки до записи undo history.

## Success Criteria

- **SC-001**: На согласованном WebView2 p95 обновления локального кадра не превышает 33 мс на слое 800×400 с 4×4 mesh и кириллицей с обводкой.
- **SC-002**: Пиковая память renderer документирована и не включает копии предыдущих деформированных кадров.
- **SC-003**: Точный preview p95 измеряется отдельно от времени кадра и не превышает 300 мс на согласованном компьютере для контрольного региона.
- **SC-004**: Точный preview и экспорт совпадают по декодированным пикселям при одинаковом документе.

## Assumptions

- PixiJS рассматривается только в изолированном сравнении. В shipped UI не добавляется сторонняя зависимость без измеримого выигрыша относительно минимального WebGL renderer.
- Режим mesh v1 остаётся совместимым; новые узлы используют mesh v2.
- WebView2 может быть недоступен в тестовом окружении; в этом случае статус интеграционной проверки остаётся открытым.
