# Feature Specification: Экономная композиция preview

**Feature Branch**: `043-preview-compose`
**Created**: 2026-10-18
**Status**: Implemented
**Input**: Reduce preview composition memory while preserving full-render pixels.

## User Scenarios & Testing

### User Story 1 — Получить быстрый локальный preview (Priority: P1)
Редактор видит образец текста на нужном участке страницы, не ожидая композиции всей полноразмерной страницы.

**Independent Test**: Для закреплённого региона сравнить декодированные пиксели нового preview с полным рендером при identity и перемещённом тексте; измерить время и peak RSS на большом листе.

**Acceptance Scenarios**:

1. **Given** одинаковые изображение, регион и стиль, **When** получается preview, **Then** его декодированные пиксели совпадают с crop полного рендера.
2. **Given** большой лист и маленький текстовый регион, **When** композиция завершена, **Then** промежуточная композиция занимает только необходимые пиксели preview.
3. **Given** вырезанный слой выходит за bbox, **When** строится preview, **Then** origin и видимые пиксели слоя сохраняются без обрезания.

## Requirements

- **FR-001**: Локальный точный preview должен сохранять цвет, alpha composition и clipping полного renderer-а.
- **FR-002**: Путь выдачи текстового слоя должен уметь пропускать ненужную сборку полноразмерной RGB-страницы.
- **FR-003**: Композиция preview должна работать на минимальном crop, содержащем исходный bbox и фактические ink bounds.
- **FR-004**: Экспорт и `Typesetter.render` сохраняют прежний публичный контракт.
- **FR-005**: Изменение принимается только при точном совпадении декодированных пикселей и измеряемом снижении peak RSS без ухудшения времени.

## Success Criteria

- **SC-001**: Все проверки pixel identity для обычного и перемещённого текста проходят.
- **SC-002**: На странице 2500×3500 три замера нового пути показывают меньший peak RSS и не более чем на 5% худшую медиану времени относительно полного рендера.
- **SC-003**: Все существующие типографские и API preview тесты проходят.

## Assumptions

- Изменяется только composition API локального preview; full export продолжает строить полную страницу.
- Замер синтетической большой страницы дополняет тесты визуальной идентичности и не является обещанием скорости на каждой странице.
