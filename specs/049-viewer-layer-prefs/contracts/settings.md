# Contract: настройки слоёв

## `PUT /api/settings`

Тело запроса (частичный патч):

```json
{
  "viewer_show_boxes": false,
  "viewer_show_mask": true
}
```

Ответ — существующий `{"settings": {...}}`, где оба ключа присутствуют.

Правила:

- Оба ключа булевы; отсутствие ключа при чтении означает `true`.
- Патч не меняет другие настройки.
- Запись атомарна для пары ключей: оба значения отправляются вместе.
- Ошибка запроса не меняет видимость слоя в текущей сессии и показывается пользователю.

## `GET /api/bootstrap`

`settings.viewer_show_boxes` и `settings.viewer_show_mask` используются для начального состояния `ViewerState` до открытия страницы.

## Совместимость

Старый `settings.json` без ключей даёт `true`/`true`. Формат документа страницы и другие API не меняются.
