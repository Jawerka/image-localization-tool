# Manual Validation: Состояние слоёв и очередь

1. Запустить приложение с `settings.json` без новых ключей: рамки и маска включены.
2. Выключить рамки кнопкой, маску клавишей `M`, закрыть и снова открыть приложение: рамки скрыты, маска скрыта.
3. Повторить для всех четырёх комбинаций (вкл/выкл для каждого слоя).
4. Переключить страницу и проект: выбранная комбинация не меняется.
5. Быстро нажать кнопку слоя несколько раз: после завершения запросов в `data/settings.json` последнее состояние.
6. Скрыть рамки, создать регион: рамки включаются, и включённое состояние сохраняется после перезапуска.
7. Отключить сайдкар или сеть, переключить слой: появляется сообщение об ошибке, приложение продолжает работать.
8. Запустить обработку, открыть «Страницы»: блока очереди нет. Открыть «Очередь»: блок и список очереди на месте; подвал с прогрессом виден в обеих вкладках.
9. Выполнить `flutter analyze`, `flutter test` и `python -m pytest tests/unit/test_app_settings.py -q`.
