# Data Model: Состояние слоёв просмотрщика и очередь во вкладке

## `AppSettings` (схема 1)

Добавляются два необязательных поля:

- `viewer_show_boxes: bool = true` — показывать слой рамок.
- `viewer_show_mask: bool = true` — показывать слой маски.

Правила:

- `from_dict` без ключей подставляет `true`.
- Небулево значение нормализуется в `true`.
- `to_dict` всегда пишет оба ключа.
- `save` пишет их в `data/settings.json` вместе с остальными настройками.

## `Config`

Те же два поля с дефолтом `true`; в `settings.json` они не являются полями пайплайна и в задание воркера не входят.

## `ViewerState`

- `showBoxes`: текущая видимость рамок.
- `showMask`: текущая видимость маски.
- `restoreLayers(boxes, mask)`: применить сохранённые значения без записи.
- Колбэк изменения слоёв вызывается после любого изменения `showBoxes`/`showMask`, включая автоматическое включение рамок при создании региона.

## Согласование

`WorkspaceState.applyBootstrap` передаёт значения из настроек в `ViewerState` до открытия активной страницы. Изменения `ViewerState` ставятся в очередь на `PUT /api/settings`; последнее состояние в очереди побеждает.
