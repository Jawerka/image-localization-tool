# Feature Specification: Inspector (Инспектор региона)

**Feature Branch**: `024-inspector`

**Created**: 2026-10-10

**Status**: Implemented

**Input**: Plan (сплит 022–026): 024 = интерьеры правого рельса вместо заглушек 022. Область зафиксирована в 025 spec: `style.html`/`sfx.html` и рельс отчёта `batch-run` — это режимы инспектора, они уходят в 024. Референсы: `web/js/inspector.js` (поведение), `web/js/inspector_render.js` (skip-перерисовки, `details`), `web/js/state.js` (правки/сохранение), `web/mockups/next/main-editor.html` (карточки «Текст»/«Страница»), `style.html` (стиль региона), `sfx.html` (звук), `batch-run.html` (отчёт). Механика: `ChangeNotifier` без новых пакетов; документ/черновик/история/409 — из 023 (`ViewerState.editDocument`); выделение — единый id с канвасом 023; экраны/диалоги — 025. Правит тот же документ, что канвас; отдельных API-контрактов не добавляется, кроме серверных gap-fix (см. FR-020).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Карточки регионов и выделение (Priority: P1)

Вкладка «Текст» правого рельса показывает карточки всех регионов документа: номер, заголовок (оригинал/перевод), флаги «Пропущен», «Не влез», «Звук»; свёрнутая карточка — строка превью (перевод · тип · говорящий), выбранная — развёрнута. Клик по карточке выделяет регион (тот же id, что на канвасе), клик по рамке на канвасе подсвечивает карточку и прокручивает к ней список. В шапке — стрелки «предыдущий/следующий регион» со счётчиком «N / M»; кнопки «Добавить регион» (создаёт в центре видимой области, как веб) и «Следующая проблема» (N). Пустые состояния: нет проекта, нет страницы, документ грузится, 0 регионов, страница в прогоне.

**Why this priority**: Карточка — точка входа во все правки; без неё инспектор бесполезен, а канвас 023 уже даёт выделение, которое надо показать.

**Independent Test**: Widget-тесты подают документ и выделение и проверяют карточки, флаги, скролл, пустые состояния; ручная проверка синхронизации с канвасом.

**Acceptance Scenarios**:

1. **Given** документ с регионами, **When** вкладка «Текст» открыта, **Then** каждая карточка показывает номер, заголовок и флаги (skip/overflow/sfx); свёрнутые — превью «перевод · тип · говорящий».
2. **Given** регион выбран на канвасе, **When** рельс перерисован, **Then** его карточка развёрнута, выделена и видима (список проскроллен).
3. **Given** карточка региона, **When** клик по её шапке, **Then** регион выделен у канваса (`viewer.selectedRegionId`), ручки рамки показаны.
4. **Given** стрелки в шапке инспектора, **When** «следующий/предыдущий», **Then** выделение переходит по порядку документа с заворотом; счётчик «N / M» совпадает с позицией.
5. **Given** кнопка «Добавить регион», **When** нажата, **Then** создаётся регион в центре видимой области, выделяется, слой рамок включается (как `blankRegion` веба).
6. **Given** нет проекта/страницы/регионов/документ грузится или страница в прогоне, **When** рельс рендерится, **Then** показывается соответствующее ожидающее состояние (022), а не пустой список.

### User Story 2 - Тексты с автосохранением (Priority: P1)

Развёрнутая карточка редактирует: «Перевод» (главное поле, многострочное), «Оригинал» (сворачиваемая секция), «Тип» (диалог/рассказ/заголовок/звук/мысль/надпись + неизвестное значение), «Говорящий». Правки текста/перевода/говорящего уходят на сервер сразу после паузы 500 мс (одна правка на серию ввода — коалесинг), тип — сразу без паузы; чип показывает «Сохраняем…» → «Автосохранено». Непустой перевод выставляет `translation_locked` (как веб). Если на странице уже есть неприменённый черновик (023), текстовые правки остаются в нём до «Готово» (зеркало `editDocument`). Ctrl+Z вне поля откатывает текстовую правку; набор в поле не перехватывается хоткеями.

**Why this priority**: Перевод — главное содержание ручной правки; веб-паритет требует автоприменения текста без «Готово».

**Independent Test**: State-тесты debounce/коалесинга/locked и черновика; widget-тест полей и чипа; ручная проверка «печатаем — сохраняется».

**Acceptance Scenarios**:

1. **Given** выбранный регион, **When** текст правки перевода набран, **Then** через паузу уходит один `PUT /api/pages/{id}/document`, чип становится «Автосохранено», версия растёт.
2. **Given** быстрый набор нескольких символов, **When** пауза наступила, **Then** уходит один PUT с итоговым текстом (коалесинг), история undo — одна запись.
3. **Given** непустой перевод, **When** правка сохранена, **Then** `translation_locked = true`; пустой перевод снимает флаг.
4. **Given** пустое поле «Кегль» (STYLE), **Then** … (см. US3); здесь: пустой перевод — поле остаётся пустым, перевод не «достаётся» из оригинала.
5. **Given** на странице неприменённый черновик канваса, **When** правится перевод, **Then** правка уходит в черновик (пилюля «N правок»), ничего не сохраняется до «Готово».
6. **Given** фокус в поле ввода, **When** нажата «B»/«V»/стрелка, **Then** хоткей не срабатывает (ввод текста); Ctrl+Z в поле отменяет ввод штатно, вне поля — правку документа.

### User Story 3 - Стиль региона (Priority: P2)

Секция «Стиль» развёрнутой карточки: шрифт (список `GET /api/fonts` с образцом выбранным шрифтом, стрелки ←/→ по списку), кегль (override: пусто = «авто · N», границы из настроек `min_font_size`/`max_font_size`, кнопки −/+ с шагом 1 (Shift 10), кламп, подсказка о границах), «ПРОПИСНЫЕ», чернила «Чёрный/Белый» (`fill_rgb` + `fill_locked`), заливка и обводка (цвет), толщина обводки (0 = авто, включение `stroke_mode: custom`), «Искривление» (пресеты Нет/Дугой вверх/Дугой вниз/Кольцо/Волна/Флаг/Перспектива/Сетка + ползунок изгиба −1…1), «Сбросить стили» (поворот 0, warp нет). Все правки стиля — в черновик («N правок» → «Готово», PUT 023). Стили проекта: чипы из `GET /api/project/styles` применяются к региону одним нажатием, «Сохранить стиль» добавляет текущий стиль региона под именем «Стиль N» через `PUT /api/project/styles`. Копирование стиля (Ctrl+Shift+C) и вставка (Ctrl+Shift+V) работают вне полей ввода и не меняют документ до «Готово». Предпросмотр образца и штрихов — US4.

**Why this priority**: Стиль — вторая по частоте ручная операция после текста; но без текста (US2) карточка неполна.

**Independent Test**: State-тесты клампов/пресетов/closed-form warp, применения стиля проекта, clipboard; widget-тест полей и кнопок; ручная проверка «правка → Готово → результат».

**Acceptance Scenarios**:

1. **Given** регион без override, **When** «Кегль +», **Then** значение = авто-кегль + 1 (или нижняя граница), клампится в границы настроек; пустое значение показывает placeholder «авто · N».
2. **Given** ползунок изгиба, **When** движение, **Then** `style.warp.bend` меняется −1…1 одной записью истории (коалесинг драга); пресеты проставляют `kind` и дефолтный bend, как `applyCardWarp` веба.
3. **Given** чип стиля проекта, **When** нажат, **Then** стиль накладывается поверх стиля региона (warp — слиянием), правка в черновике.
4. **Given** «Сохранить стиль», **When** нажато, **Then** `PUT /api/project/styles` с новым списком, чипы обновляются; ошибка — полоса, список не теряется.
5. **Given** Ctrl+Shift+C на регионе, **When** затем Ctrl+Shift+V на другом, **Then** стиль второго обновлён в черновике; при вводе в поле хоткей не срабатывает.
6. **Given** «Сбросить стили», **When** нажато, **Then** rotation = 0, warp = `{kind: none, bend: 0, quad: null, mesh: null}`, остальные поля стиля не трогаются (как веб).

### User Story 4 - Предпросмотр стиля на канвасе (Priority: P2)

При выделении региона и после правок стиля (пауза 400 мс) рельс запрашивает `POST /api/pages/{id}/preview-region {region_id}`; сервер возвращает PNG-кроп отрисованного региона и заголовки смещения `X-Offset-X/Y`. Картинка кладётся на канвас поверх результата в координатах листа (перекрывая старый текст региона), старый предпросмотр заменяется без мигания; статус («Обновляем предпросмотр», ошибка) показывается в карточке; снятие выделения/смена страницы очищает предпросмотр.

**Why this priority**: Без превью правки стиля невидимы до «Готово»; это главный инструмент подбора. Но рендер канваса без него работоспособен.

**Independent Test**: State-тест расписания/отмены/гонок токенов; widget/painter-тест позиции; ручная проверка.

**Acceptance Scenarios**:

1. **Given** регион выделен, **When** пауза истекла, **Then** ушёл один POST preview-region, PNG декодирован и отрисован в позиции (X-Offset) в масштабе листа.
2. **Given** серия правок стиля, **When** они идут подряд, **Then** запрос откладывается до паузы; промежуточные ответы не перекрывают свежий (токен).
3. **Given** выделение снято/страница сменилась, **When** рельс перерисован, **Then** предпросмотр убран, запросы отменены.
4. **Given** сервер вернул ошибку (нет картинки/региона), **When** ответ получен, **Then** превью пусто, статус ошибки в карточке, сцена не ломается.

### User Story 5 - Действия региона и звуки (Priority: P2)

В развёрнутой карточке: «Распознать», «Перевести заново», «Сократить» → `POST /api/pages/{id}/action {action, region_id}` с ожиданием «Ждёт сервер LLM»; «Не переводить» (skip) — переключатель, сохраняется сразу (как веб) и виден флагами; «Удалить» — удаление региона из черновика. Для регионов типа «звук»: чип «распознан как звук», секция «Звук» — текст замены (обычное поле перевода), блок «Подобранный стиль» (образец + кнопки «Подобрать стиль заново» и «Рамка» = выделить регион), подсказка «Почему звук», ссылка на другие звуки страницы. «Подобрать заново»: черновик сначала применяется (если был), затем `POST /api/pages/{id}/regions/{rid}/sfx-style`, документ и стиль перечитываются (сервер сохраняет сам).

**Why this priority**: Действия дополняют ручную правку; звуки — редкий тип, но контракт существует и был обещан карточками 024.

**Independent Test**: State-тесты тел запросов, skip-сейва, sfx-цикла; widget-тест кнопок и состояний; ручной прогон действия против живого сайдкара.

**Acceptance Scenarios**:

1. **Given** регион, **When** «Распознать», **Then** уходит POST action с `region_id`, карточка показывает ожидание, событие `page.updated` обновляет документ; ошибка — полоса.
2. **Given** регион, **When** «Не переводить», **Then** `skip` меняется и сохраняется немедленным PUT; флаг виден на карточке и канвасе.
3. **Given** sfx-регион, **When** «Подобрать стиль заново», **Then** несохранённый черновик применяется, уходит POST sfx-style, документ перечитывается, стиль региона обновлён, статус «Готово» в карточке.
4. **Given** sfx-регион с распознанным текстом, **When** карточка развёрнута, **Then** видны чип «распознан как звук», поле замены и подсказка «Почему звук»; «Другие звуки страницы» перечисляет sfx-регионы и выделяет по клику.

### User Story 6 - Вкладка «Страница» и отчёт прогона (Priority: P3)

Вкладка «Страница»: статус страницы, OCR, переводчик, очистка, устройство, тайминги этапов, предупреждения и ошибка страницы; кнопки «Перевести заново» (`POST /api/jobs/translate {scope: page}`) и «Сбросить правки» (подтверждение → `POST /api/pages/{id}/reset`, история очищается, документ перечитывается). Пока идёт прогон (или выбран режим «Прогон»), доступна вкладка «Отчёт»: счётчики «Всего/Готово/Ошибки/Без LLM/В очереди/Идёт», строка паузы, баннер первой ошибки с «Повторить ошибки» и «Открыть лог», чек-лист после прогона (3 пункта, локально, без сохранения).

**Why this priority**: Диагностика и итоги прогона — удобство; основные правки доступны без них.

**Independent Test**: Widget-тесты вкладок, фактов, отчёта при batch; state-тест reset-цикла; ручная проверка на прогоне.

**Acceptance Scenarios**:

1. **Given** готовая страница, **When** вкладка «Страница», **Then** факты совпадают с документом (`ocr_engine`, `translator_engine`, тайминги через подписи 022), предупреждения и ошибка страницы видны.
2. **Given** «Сбросить правки», **When** подтверждено, **Then** POST reset, история очищена, документ перечитан (черновик не сохраняется).
3. **Given** идёт batch, **When** открыт инспектор, **Then** вкладка «Отчёт» показывает счётчики из workspace, пауза/ошибка видны; «Повторить ошибки» шлёт retry-errors, «Открыть лог» открывает файл лога хоста.
4. **Given** batch завершён, **When** режим «Прогон» выбран, **Then** вкладка «Отчёт» остаётся доступной; в других режимах инспектор возвращается к карточкам/фактам.

### Edge Cases

- Документ ещё грузится: вкладка «Текст» — «Страница открывается…»; вкладка «Страница» — «Нет открытой страницы».
- 0 регионов: «Нет регионов. Добавьте рамку или запустите перевод.» + «Добавить регион».
- Неизвестный тип региона: не теряется — добавляется в список типов как есть (как `typeOptions`).
- Неизвестный `warp.kind`: пресеты не подсвечены, регион не ломается.
- Кегль вне границ: подсказка предупреждает и значение клампится при сохранении (как `clampFont`).
- Быстрый ввод в поле во время `page.updated`: перерисовка не сбрасывает фокус/каретку (skip-перерисовка контролируется: поле не пересоздаётся, если контент тот же).
- 409 при автосохранении текста: полоса ошибки, документ перечитывается, локальный текст не теряется молча (023-семантика).
- Смена страницы во время preview-запроса: ответ игнорируется (токен), кэш не отравляется.
- sfx-style с неприменённым черновиком: черновик сначала применяется (иначе серверный документ разойдётся с локальным).
- Стили проекта пусты: секция чипов скрыта; сохранение первого стиля возможно.
- Шрифты не загрузились (ошибка сети): список пуст, поле «Шрифт» показывает «По умолчанию», правка идёт без образца.
- Окно узкое/масштаб UI: рельс прокручивается, карточки не ломают layout.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Инспектор MUST заменить заглушку 022: шапка (стрелки регионов, счётчик, вкладки «Текст»/«Страница» + условный «Отчёт») и интерьеры; выделение MUST быть единым id с канвасом 023 в обе стороны.
- **FR-002**: Вкладка «Текст» MUST рисовать карточки всех регионов документа: номер, заголовок (`text || translation || «Пустой регион»`), флаги «Пропущен», «Не влез», «Звук»; свёрнутые — превью «перевод · тип · говорящий»; выбранная — развёрнута и видима (автоскролл).
- **FR-003**: Шапка MUST листать выделение по порядку документа с заворотом и показывать «N / M»; «Добавить регион» MUST создавать `blankRegion` в центре видимой области и выделять его; «Следующая проблема» MUST использовать `focusNextProblem` (N).
- **FR-004**: Развёрнутая карточка MUST давать поля «Перевод» и «Оригинал» (оригинал — сворачиваемая секция), «Тип» (6 типов + неизвестные), «Говорящий».
- **FR-005**: Правки `text`/`translation`/`speaker` MUST сохраняться немедленно с паузой 500 мс и коалесингом на поле (одна запись истории на серию), `type` — немедленно без паузы; при активном черновике канваса (023) текстовые правки MUST оставаться в черновике до «Готово» (зеркало `editDocument`).
- **FR-006**: Непустой `translation` MUST выставлять `translation_locked`, пустой — снимать; чип состояния MUST показывать «Сохраняем…» при незавершённом сохранении и «Автосохранено» после.
- **FR-007**: Секция «Стиль» MUST давать: шрифт (список `GET /api/fonts`, образец, ←/→-навигация), кегль override (границы из `min_font_size`/`max_font_size`, ±1/±10, кламп, placeholder «авто · N»), «ПРОПИСНЫЕ» (`style.uppercase`), чернила «Чёрный/Белый» (`fill_rgb` + `fill_locked`), заливка/обводка (hex-цвета), толщина обводки (0=авто, иначе `stroke_mode: custom`), искривление (пресеты none/arc-up/arc-down/ring/wave/flag/perspective/mesh + bend −1…1 с клампом и коалесингом), «Сбросить стили» (rotation 0 + warp none; остальные поля не трогаются).
- **FR-008**: Все правки стиля MUST идти в черновик 023 («N правок» → «Готово» → PUT); «N правок» MUST считать только неприменённые правки (текстовые автосохранения в счёт не входят), undo/redo MUST работать по одной записи.
- **FR-009**: Стили проекта MUST загружаться из `GET /api/project/styles` при открытии проекта и при смене проекта; чип MUST накладывать стиль поверх стиля региона (warp — слиянием, как `applyProjectStyle` веба); «Сохранить стиль» MUST добавлять текущий стиль под именем «Стиль N» через `PUT /api/project/styles`.
- **FR-010**: Копирование стиля (Ctrl+Shift+C) MUST запоминать `style` выделенного региона в памяти сессии; вставка (Ctrl+Shift+V) MUST накладывать копию на выделенный регион (warp — слиянием) в черновик; хоткеи MUST NOT срабатывать при вводе текста.
- **FR-011**: При выделении региона и правках его стиля инспектор MUST планировать предпросмотр `POST /api/pages/{id}/preview-region` с паузой 400 мс; картинка MUST рисоваться на канвасе в позиции `X-Offset-X/Y` координат листа поверх результата; промежуточные ответы MUST отбрасываться (токен); снятие выделения и смена страницы MUST очищать предпросмотр; ошибка MUST показываться статусом, не ломая сцену.
- **FR-012**: Действия «Распознать», «Перевести заново», «Сократить» MUST слать `POST /api/pages/{id}/action {action, region_id}`; карточка MUST показывать ожидание («Ждёт сервер LLM»), ошибка — полосой; «Не переводить» MUST переключать `skip` немедленным сохранением; «Удалить» MUST удалять регион из черновика.
- **FR-013**: Sfx-регионы MUST показывать чип «распознан как звук», поле замены, блок подобранного стиля и подсказку «Почему звук»; «Подобрать стиль заново» MUST применить черновик (если есть), затем `POST /api/pages/{id}/regions/{rid}/sfx-style`, перечитать документ (сервер сохраняет стиль сам) и показать статус готовности/ошибки; «Другие звуки страницы» MUST выделять регион по клику.
- **FR-014**: Вкладка «Страница» MUST показывать статус/OCR/переводчик/очистку/устройство/тайминги/предупреждения/ошибку страницы и кнопки «Перевести заново» (`POST /api/jobs/translate {scope: page}`) и «Сбросить правки» (подтверждение → `POST /api/pages/{id}/reset` → очистка истории → перечитка).
- **FR-015**: Вкладка «Отчёт» MUST появляться во время batch или в режиме «Прогон» и показывать счётчики workspace (всего/готово/ошибки/без LLM/в очереди/идёт), паузу, первое сообщение ошибки с «Повторить ошибки» (`POST /api/jobs/retry-errors`) и «Открыть лог» (хост), чек-лист после прогона (локальный).
- **FR-016**: Хоткеи канваса 023 MUST NOT перехватываться при вводе в полях инспектора; Ctrl+Shift+C/V MUST быть добавлены как хоткеи стиля; однобуквенные MUST NOT срабатывать в полях (существующая проверка `_isTyping`).
- **FR-017**: Состояние MUST оставаться `ChangeNotifier` (расширение `ViewerState` + проброс из `WorkspaceState`), без новых пакетов; ошибки API MUST показываться полосой/статусом, не замораживая рельс.
- **FR-018**: Поведение 022/023 MUST сохраняться: пустые состояния 022, черновик/пилюля/страж ухода/409, батч-блок и job pill; `flutter analyze` чистый, `flutter test` зелёный.
- **FR-019**: UI MUST следовать мокапам структуры (`main-editor`, `style`, `sfx`, `batch-run`) и токенам `web/tokens.json`; точный пиксель-паритет не требуется.
- **FR-020**: Серверные gap-fix допустимы только при обнаружении недостающего контракта в прогоне (как в 025); при отсутствии gap'ов `src/app/` не меняется.

### Key Entities

- **RegionCard**: проекция `Region` документа + индекс; флаги `skip/overflow/sfx`; превью для свёрнутого состояния.
- **InspectorState** (часть `ViewerState`): `tab` (`text|page|report`), `fonts[]` (`{id, family, category, cyrillic}` + загруженное семейство Flutter), `styleLibrary[]`, `styleClipboard`, `pendingAction {regionId, action}`, `sfxNote {regionId, status, message}`, `stylePreview {status, message}`, предпросмотр-картинка и смещение.
- **FontFace**: `{id, family, category, cyrillic}` из `GET /api/fonts`; файл `/api/fonts/{id}/file`.
- **ProjectStyle**: `{name, style{...}}` из `GET/PUT /api/project/styles`.
- **PreviewRegion**: PNG + `{x, y}` из заголовков `X-Offset-X/Y` (`POST /api/pages/{id}/preview-region`).
- **PageFacts**: `{status, ocr_engine, translator_engine, inpainter, device, timings, warnings, error}`.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Полный цикл правки текста: печать → «Автосохранено» → версия документа выросла; undo отменяет ровно последнюю серию ввода (ручная проверка + state-тесты).
- **SC-002**: Правка стиля (шрифт/кегль/цвет/искривление) видна на канвасе через предпросмотр, попадает в черновик, после «Готово» результат перевёрстывается (статус «есть правки» → «идёт» → «готово»).
- **SC-003**: Sfx-регион: «Подобрать стиль заново» обновляет стиль и текст в карточке без потери черновика (ручной прогон против сайдкара).
- **SC-004**: Во время прогона отчёт показывает счётчики, совпадающие с батч-блоком; «Повторить ошибки» работает.
- **SC-005**: «Сбросить правки» страницы возвращает серверный документ; подтверждение обязательно; черновик не улетает.
- **SC-006**: `flutter analyze` чистый, `flutter test` зелёный (новые state/widget-тесты инспектора); pytest и JS-наборы не меняются.
- **SC-007**: Синхронизация выделения канвас ↔ инспектор и счётчик «N / M» совпадают на документе с 15+ регионами (ручная проверка, smoke-прогон).

## Assumptions

- Контракт API уже включает: `GET /api/pages/{id}`, `PUT /api/pages/{id}/document`, `POST /api/pages/{id}/action`, `POST /api/pages/{id}/reset`, `POST /api/pages/{id}/preview-region`, `POST /api/pages/{id}/regions/{rid}/sfx-style`, `GET /api/fonts`, `GET /api/fonts/{id}/file`, `GET/PUT /api/project/styles`, job-эндпоинты; gap-fix — только при обнаружении пробела в прогоне.
- Канвас-слой 023 предоставляет `ViewerState`/`editDocument`/выделение/кэш изображений; 024 не меняет модель документа, только наполняет её полями стиля/текста.
- Шрифты грузятся через `FontLoader` (Flutter SDK) из `/api/fonts/{id}/file`; при неудаче список остаётся без образцов — правка не блокируется.
- Предпросмотр стиля отражает серверный (сохранённый) документ — как в вебе; отложенные правки до «Готово» серверу не видны (документированное поведение веба).
- Мокапы — структурный референс; визуальная полировка ограничена токенами темы.
- Чек-лист отчёта — локальный UI без сохранения в пакет (как в мокапе).
