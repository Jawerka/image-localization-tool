# Quickstart: Portable Project

1. Open app, import pages (Open files / folder).
2. Drag thumbnails in the left list to reorder.
3. File → Save project as… → choose `demo.ilt.zip`.
4. File → Close project (confirm if dirty).
5. File → Load project… → select `demo.ilt.zip` on another machine or after restart.
6. Confirm page order and documents match; Ctrl+S saves over the same path.
