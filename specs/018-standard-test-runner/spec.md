# Feature Specification: Стандартный прогон тестовых изображений

**Feature Branch**: `codex/018-standard-test-runner`
**Created**: 2026-11-14
**Status**: Specified
**Input**: Кнопки JSON сверху/снизу без плавающей панели; единый автономный сценарий тестирования и отчётов.

## User Scenarios & Testing
### User Story 1 — Автономный прогон (P1)
Одна команда обрабатывает весь набор либо выбранную группу без сопровождения агентом.
**Independent Test**: Два исходника обрабатываются последовательно, маски исключены, отчёты одинаковой структуры.
**Acceptance**: Сбой страницы отражается в отчёте и коде завершения, очередь продолжается.
### User Story 2 — Возобновление (P1)
**Independent Test**: Повторный запуск не отправляет готовые страницы; изменение исходника, кода или конфигурации отклоняет продолжение.
**Acceptance**: Повреждённый результат обнаруживается; зависшая страница завершается по тайм-ауту; параллельные запуски не пишут в один каталог.
### User Story 3 — Приёмка (P1)
**Independent Test**: Верхние и нижние кнопки экспортируют одинаковый JSON оценок/комментариев.
**Acceptance**: Панель не перекрывает изображения; прежние оценки существующей галереи сохраняются после обновления.
### Edge Cases
Пустой набор, маска с опечаткой msak, дубли имён в разных папках, авария процесса, прерывание, повреждённый конфиг, недоступное хранилище браузера, специальные символы.

## Requirements
### Functional Requirements
- **FR-001**: Использовать только PagePipeline v2 последовательно, отдельным процессом на страницу.
- **FR-002**: Рекурсивный стабильный набор без масок и html, с выбором групп.
- **FR-003**: Фиксировать конфигурацию без ключа, хеши кода/исходников/результатов, времена, предупреждения и ошибки.
- **FR-004**: Проверять условия и целостность при продолжении; повторять ошибки только по явной опции.
- **FR-005**: Тайм-аут/авария страницы не обрывает очередь; каталог защищён от параллельной записи.
- **FR-006**: Единые manifest.json, report.json, summary.json, events.jsonl, index.html; статус и галерея доступны без OCR.
- **FR-007**: Тёмная галерея только итогов, оценки 1–5, комментарии, JSON сверху/снизу; без закрепления, с сохранением прежних оценок.
- **FR-008**: Предпросмотр состава/адреса без отправки изображений; рабочий сценарий без API-ключа.
- **FR-009**: Принимать явный список локальных файлов через аргументы или TXT/JSON-файл, в том числе вне test-img; сохранять порядок, устранять повторы и заранее обнаруживать отсутствующие файлы.
- **FR-010**: В синхронном режиме показывать в консоли текущую страницу, стадии, время ожидания, ошибки и итоговые счётчики; в фоне сохранять такой же вывод в runner.log.
### Key Entities
Прогон, исходник, результат страницы, событие, оценка пользователя.

## Success Criteria
- **SC-001**: Ноль ручных опросов агента для каждой страницы при полном прогоне.
- **SC-002**: Ноль повторных обработок готовых неизменённых страниц при возобновлении.
- **SC-003**: Ошибка не теряет готовые результаты и отражается в итоговом статусе.
- **SC-004**: Обновление текущей галереи 53 страниц без повторной отправки и смены ключа оценок.

## Assumptions
Стандартизируется сценарий, а не побитовая детерминированность LLM. Сервер и модели выбираются конфигурацией. Разрешение сети определяет среда запуска. Качество оценивает пользователь. Для проверки инструмента достаточно изолированных тестов очереди и малого реального прохода; весь трёхчасовой набор повторять не требуется.
