# Результаты оценки пайплайна

Эталонные страницы в репозиторий не входят. Прогон делается локально:

```powershell
python scripts\eval_pipeline.py --images path\to\pages
```

В папке нужны пары `page.ext` + `page-mask.ext` (красные прямоугольники поверх букв).

## Метрики

- **Ink recall** — доля пикселей букв внутри эталона, которые закрыла маска.
- **Spill** — доля маски за пределами эталона, расширенного на 6 px.
- **Residue** — доля пикселей букв, которые после очистки всё ещё отличаются от фона.
- **Halo** — грязь в полосе 3 px вокруг букв.

## Сводка (локальный прогон, 2026-10-02)

На пяти эталонных страницах с доступным LLM-сервером:

| Страница | Ink recall | Spill | Время | Примечание |
|----------|------------|-------|-------|------------|
| 1 | 99.8% | 2.1% | ~49 с | SFX не переводились |
| 2 | 100% | 4.2% | ~31 с | |
| 3 | 100% | 1.5% | ~51 с | имя на скринтоне чистится грубее |
| 4 | 100% | 0% | ~28 с | фото не задето |
| 5 | 100% | 0% | ~20 с | заголовок; вывески `sign` не тронуты |

Повторная очистка и вёрстка (`--rerender`) давала residue 0% и halo ≤ 0.01% при ink recall 100%.

Это не гарантия качества на произвольных страницах: узкие баллоны переносятся по слогам, текст на скринтоне чистится хуже, без LLM работает более слабый фолбэк RapidOCR + Argos.

Затравка фона вне ореола букв, силуэт только при покрытии буквоподобных компонент ≥ 80%, заливка с фиксированным диапазоном и отбраковкой утечки. Сравнение `output/mask-before` → актуальный код (`output/mask-probe/out6` для четырёх страниц, `output/mask-after` для остальных):

|----------|----------------|------------------|------------|
| 0001_1__ | 100% → 100% | 25.6% → 23.8% | белые овалы на месте |
| 0002_2__ | 74.2% → 65.3% | 27.2% → 25.6% | часть смешанных с рисунком «баллонов» ушла в буквы |
| 0008_8__ | 79.2% → 65.6% | 27.2% → 19.5% | меньше заливки фона, часть букв не закрыта |
| Ch1_Pg223 | 87.3% → 73.7% | 9.1% → 16.0% | нет полосы «A-AHEM» и прямоугольников по тёмным углам; эталон — прямоугольники букв, поэтому recall ниже |
| test-1…5, dwSuivL | без регресса > 0.5 п.п. | | |

SFX (`--sfx-mode replace`): ink на эталонах sound-ref по-прежнему низкий (оверлей, не баллоны); заметного регресса нет.

## Проверка маски текста с белой обводкой (2026-10-30)

Локальный эксперимент: замкнутая светлая обводка с тёмными буквами внутри
имеет приоритет над заливкой облачка и инверсией плотной маски. Широкое
светлое поле отбрасывается по толщине относительно высоты букв.
Для остальных случаев сохранён прежний алгоритм, включая эвристику инверсии.

Сравнение выполнено через `PagePipeline.clean` на одинаковых сохранённых
регионах `output/mask-before`, с `Config()` и `sfx_mode=replace`.
Повторные OCR, перевод и inpaint отключены; это проверка масок, а не
качества очищенной или переведённой страницы. Метрики считаются в исходном
разрешении. Эталон используется только для оценки, не для построения маски.

| Страница | Ink до → после | Spill до → после |
|----------|----------------|------------------|
| Ch1_Pg223 | 73.68% → 98.56% | 15.96% → 1.05% |
| Остальные 15 локальных страниц | без изменений | без изменений |

Набор: `0001_1__`, `0002_2__`, `0008_8__`, `Ch1_Pg223`, `dwSuivL`,
`test-1`…`test-5`, шесть `sound-ref`. Неизменность остальных результатов
не означает высокого качества: например, ink на `0002_2__` — 65.30%,
на `0008_8__` — 65.64%, на `test-4` — 91.07%; проблемы SFX сохраняются.
Текущая проверка не покрывает все виды цветной, разорванной или смешанной
обводки. Код остаётся экспериментальным улучшением для светлой обводки.

Локальные артефакты: `output/mask-recheck/{before,after}` (маски и оверлеи),
`output/mask-recheck/comparison.json` (полные метрики),
`output/mask-recheck/run.py` (повтор расчёта: аргумент — имя папки результата).

## Светлые разнотонные облачка и звуки по умолчанию (2026-10-31)

Сегментация тёмных букв на светлом фоне больше не зависит только от цвета
кольца вокруг текста. Отбрасываются компоненты на границе кропа; отступ
оценивается по высоте букв, чтобы фрагмент рамки не раздувал маску в прямоугольник.
Контур облачка по-прежнему используется для вёрстки и резервного пути.

Повтор предыдущего mask-only сравнения на тех же 16 сохранённых наборах регионов:

| Страница | Ink предыдущий → текущий | Spill предыдущий → текущий |
|----------|--------------------------|----------------------------|
| 0001_1__ | 99.98% → 99.77% | 23.82% → 0.20% |
| 0002_2__ | 65.30% → 75.91% | 25.63% → 4.51% |
| 0008_8__ | 65.64% → 79.24% | 19.48% → 0.01% |
| Ch1_Pg223 | 98.56% → 98.56% | 1.05% → 1.05% |
| test-1 | 100% → 100% | 45.56% → 1.98% |
| test-2 | 100% → 100% | 61.40% → 0% |
| test-3 | 100% → 100% | 59.70% → 2.00% |

На 0002_2__ и 0008_8__ почти все оставшиеся пропуски находятся вне активных
распознанных областей с переводом. В сохранённых регионах есть пустые OCR/переводы:
например, SHHHCK имеет текст, но не перевод; WUH ALREADY не распознан.
Включение SFX и пересчёт старой маски не восстанавливают эти данные: нужен
полный запуск OCR/перевода. Прогон не проверяет LaMa или качество переводов.
На sound-ref качество остаётся низким; это не подтверждение качества SFX
на произвольных страницах. Исходные эталоны не используются алгоритмом.

Артефакты: `output/mask-recheck/complete-dialogue/metrics.json`, PNG маски и
JPEG оверлеи рядом. Сравнивать с `output/mask-recheck/after` (предыдущий вариант).
Новый default SFX проверен отдельно тестами настроек, снимка задания расширения,
передачи флага переводчику, фильтрации пустых переводов и смены fingerprint.
Установленные приложения не развёртывались; сохранённое отключение сохраняется.

## Попадание маски в ручную разметку (2026-10-31)

Звук с белой обводкой на пёстром фоне больше не заливается прямоугольником кропа.
Буква подтверждается, только если вокруг неё есть тонкая обводка противоположного
цвета, которая кончается, а не продолжается фоном. Линии рисунка рядом со звуком
отбрасываются, если после этого остаются буквы. Отступ такой маски — до 5 px
вместо прежних 8 px, потому что обводка уже входит в чернила. Реплики в облачках
идут прежним путём.

Оценка: `scripts/eval_masks.py`, RapidOCR + Argos, звуки включены, LaMa не запускалась.
Эталон только для отчёта. Попадание считается по виду разметки: `sound-ref` — звуки,
`002_eng` — всё, остальные страницы — текст без звуков. Запас 6 px. Покрытие —
прежний ink recall по полной маске.

| Страница | Покрытие до → после | Попадание до → после |
|----------|---------------------|----------------------|
| 002_eng | 95.56% → 94.45% | 94.21% → 97.77% |
| sound-ref (3) | 99.98% → 100% | 59.19% → 79.34% |
| sound-ref (4) | 99.92% → 99.92% | 62.72% → 95.92% |
| test-1 | 100% → 100% | 98.02% → 98.02% |
| sound-ref (1) | 3.11% → 3.11% | 79.85% → 90.26% |
| sound-ref (2) | 39.47% → 39.47% | 56.02% → 90.56% |
| sound-ref (5) | 7.63% → 5.59% | 39.74% → 47.54% |

99% попадания на всех четырёх целевых страницах не достигнуто.

На sound-ref (3) буквы звуков закрыты, но часть маски — это рисунок, который
слипается с белой обводкой (край одежды у Squeeze, поле под верхним BA-DUMP).
Отрезать его, не задев буквы, не получилось: перемычка толще, чем штрих.
На sound-ref (4) остаются мелкие фрагменты линий у Startle, около 4% маски звука.
test-1 не менялся: 98% — это прежний край диалоговой маски, не звуки.

Падение покрытия 002_eng на 1.1 п. п. — край букв на чёрном (GLANCE и соседние
звуки), где белой обводки снизу нет, плюс серые пиксели, которые метрика считает
чернилами. Расширять маску на этот край нельзя: вместе с ним возвращается чёрный
фон. sound-ref (1), (2), (5) по-прежнему упираются в обнаружение, а не в сегментацию;
у (5) более узкая маска ещё и чуть снижает покрытие.

Текстовые страницы кроме 002_eng не сдвинулись больше чем на 0.5 п. п.
Ореол после LaMa не перепроверялся: в этом прогоне очистка отключена.
Артефакты: `output/mask-eval/baseline` и `output/mask-eval/glyphs`
(`report.json`, `gallery.html`). Эталон в построении маски не участвует.

## Короткий текст, обводка и второй детектор (2026-10-31)

Это замер на местных страницах `test-img`. Он не описывает качество на произвольном комиксе.
Сервер языковой модели был недоступен, поэтому режим с VLM и проверка японского текста через
языковую модель не измерялись. Оффлайн-перевод en→ru в этом окружении не установлен:
Argos возвращает исходный текст, цифры ниже — про маску и обнаружение, не про перевод.

Короткий свободный текст с `!`, `?` или многоточием считается звуком, если это одно слово,
и повествованием, если слов больше. Ник и адрес остаются подписью. Полярность обводки
меняется только при устойчивой разнице толщины штриха. Сплошная масса толще букв вырезается.
Компонент, который касается двух противоположных краёв кропа, отбрасывается как желоб панели.
Отступ обводки — 2–3 px.

Ореол LaMa сравнивался на sound-ref (3) и (4) при отступе 2–3 px и прежнем 3–5 px.
Кольцо в 3 px на этих страницах — рисунок, не бумага. Новый отступ его не увеличил
(страница 3: 0.9375 против 0.9343; страница 4: 0.2872 и 0.2872). Отступ 2–3 px оставлен.

manga-image-translator beta-0.3. Его нет в обязательной подготовке. Без файла пайплайн
продолжается с предупреждением. Четыре оффлайн-прогона по 24 страницы запускает `scripts/ab_detectors.py`.
Результат — `output/mask-eval/ab` (`summary.json`, `index.html`). VLM — «не измерен».

модели после прогрева — 0,66 с.
