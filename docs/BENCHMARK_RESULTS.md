# Результаты оценки пайплайна

Эталонные страницы в репозиторий не входят. Прогон делается локально:

```powershell
python scripts\eval_pipeline.py --images path\to\pages
```

В папке нужны пары `page.ext` + `page-mask.ext` (красные прямоугольники поверх букв).

## Метрики

- **Ink recall** — доля пикселей букв внутри эталона, которые закрыла маска.
- **Spill** — доля маски за пределами эталона, расширенного на 6 px.
- **Residue** — доля пикселей букв, которые после очистки всё ещё отличаются от фона.
- **Halo** — грязь в полосе 3 px вокруг букв.

## Сводка (локальный прогон, 2026-10-02)

На пяти эталонных страницах с доступным LLM-сервером:

| Страница | Ink recall | Spill | Время | Примечание |
|----------|------------|-------|-------|------------|
| 1 | 99.8% | 2.1% | ~49 с | SFX не переводились |
| 2 | 100% | 4.2% | ~31 с | |
| 3 | 100% | 1.5% | ~51 с | имя на скринтоне чистится грубее |
| 4 | 100% | 0% | ~28 с | фото не задето |
| 5 | 100% | 0% | ~20 с | заголовок; вывески `sign` не тронуты |

Повторная очистка и вёрстка (`--rerender`) давала residue 0% и halo ≤ 0.01% при ink recall 100%.

Это не гарантия качества на произвольных страницах: узкие баллоны переносятся по слогам, текст на скринтоне чистится хуже, без LLM работает более слабый фолбэк RapidOCR + Argos.
