# Обновление Windows portable

## Обновление

1. Закройте Image Localization Tool.
2. Распакуйте новый portable ZIP во временную папку.
3. Откройте PowerShell и запустите скрипт из распакованного пакета:

```powershell
.\update-windows.ps1 -Bundle . -InstallRoot "D:\Documents\apps\ImageLocalizationTool"
```

Можно передать путь к ZIP вместо каталога. Скрипт проверит `release.json` и обязательные файлы, запустит временный sidecar с отдельными данными и loopback-портом, затем переключит установку. Если процесс приложения ещё работает, пакет некорректен или health check не проходит, обновление остановится либо восстановит прежнюю версию.

Старые portable-установки без `release.json` тоже поддерживаются: updater получает их версию через временный health-запуск, а затем записывает метаданные в сохранённый предыдущий релиз.

## Откат

Из активной установки запустите:

```powershell
.\rollback-windows.ps1 -InstallRoot "D:\Documents\apps\ImageLocalizationTool"
```

Откат сначала проверяет сохранённую версию, затем переключает её в активный каталог и проверяет health. При неудаче активная версия возвращается на место.

## Сохранение данных и диагностика

Каталоги `data`, `models`, `runtime`, `.resources`, `.downloads`, `.builtin` и `components` переносятся между версиями как есть. Сам updater не скачивает файлы и не завершает работающий пользовательский процесс. Держите свободное место под полную временную копию приложения. Каталог предыдущей версии и `ImageLocalizationTool.previous.json` лежат рядом с установкой; старые версии автоматически не удаляются.

Проверка готовности выполняется локально и использует временную папку данных. Временный sidecar закрывается после проверки. Ошибка содержит шаг, который не прошёл; активный каталог и предыдущий release остаются рядом для диагностики.
