# Приёмка кандидата 1.0.2

Шаблон до сборки. Статусы 1.0.1, SHA, digest и контрольные суммы прежнего выпуска сюда не переносятся. CUDA (P06) отложена.

Машинный паспорт: [ACCEPTANCE_1.0.2.json](ACCEPTANCE_1.0.2.json). Пункты без выполненного критерия имеют статус `open` и результат `incomplete`. Публикация разрешена только после заполнения паспорта на точном кандидате.

## Что входит

- Светлые буквы, обратная обводка, сохранение рисунка под прозрачными плашками, тонкие штрихи звуков.
- Роли RapidOCR: фразы заглавными, адреса автора, короткие звукоподражания.
- Пин `opencv-python` и `opencv-python-headless` 4.13.0.92 в релизной базе.

## Что не заявляется

- Идеальное распознавание SFX и универсальные 95% качества.
- CUDA в CPU-поставке.
- Закрытие T011 фичи 003 фактом публикации.

## Обязательные проверки

Двадцать четыре ID из `REQUIRED_CHECK_IDS` плюс итоговая H04. Для 1.0.1 девять из них остались открытыми; для 1.0.2 они снова требуют свежих доказательств собранных пакетов:

- T03 — обработка установленных/собранных пакетов и заявленные версии Python.
- Q02 — пайплайн, роли, перевод, маска, очистка, вёрстка; LLM отдельно от офлайн-пути.
- U08 — расширение с заявленными backend, включая Docker, и сценарий обновления.
- Q06 — время, память и диск, p50/p95 и окружение.
- P02 — light с чистого состояния, подготовка компонентов, отказ без сети.
- P01 — полный Windows-цикл EXE.
- P03 — обновление с 1.0.1 и сохранение данных.
- P05 — Docker Compose, volume, браузерный проект.
- H03 — сборка из отдельного чистого клона на релизном SHA.

Остальные обязательные ID подтверждаются заново по применимости. После Prepare сюда записываются Git SHA, SHA256 файлов и digest образа.
