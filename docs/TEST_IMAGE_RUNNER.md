# Стандартное тестирование изображений

Вверху галереи показаны обработанные страницы (включая ошибки), процент и примерное время до окончания. ETA появляется после первого результата и рассчитывается по средней длительности завершённых страниц с учётом времени текущей. Это приблизительная оценка: сложность страниц различается. Статус и готовые изображения обновляются автоматически, в том числе при открытии локального HTML; оценки и ввод комментария сохраняются без перезагрузки страницы.

Над готовым изображением нажмите «Выделить рамку» и протяните прямоугольник мышью или касанием. В конец комментария добавятся координаты верхнего левого и нижнего правого углов в процентах от изображения: начало X/Y — слева сверху, диапазон 0–100. Можно добавить несколько рамок; Esc отменяет выделение и выключает режим. Рамки восстанавливаются из комментария при открытии галереи и попадают в скачанные оценки JSON как текст комментария. Чтобы убрать рамку, удалите её строку из комментария. При выключенном режиме изображение открывается обычным нажатием.

Если очередь уже была запущена старой версией сценария, обновить только её галерею и включить наблюдение можно без повторной обработки:

```powershell
venv/Scripts/python.exe scripts/test_images.py gallery --output output/review-example --watch --background
```

Наблюдение записывает только `index.html`, `progress.js` и `gallery.log`, читает существующие отчёты и само завершается при окончании или прерывании очереди. Для новых прогонов дополнительное наблюдение не требуется.

Один сценарий: исходники → свежий PagePipeline v2 → итоговые PNG → тёмная галерея → ручные оценки JSON. Скрипт сам ведёт очередь и формирует отчёты; агент не должен опрашивать каждую страницу и писать сообщения об ожидании. Для полного набора достаточно одного фонового запуска и проверки итогового статуса по необходимости.

## Запуск

Используйте Python из окружения проекта. Установленные модели и OCR/LLM-сервер должны быть доступны, как для обычного приложения. Конфигурация задаётся явно; файл настроек не изменяется. Профиль теста всегда включает SFX replace, четыре потока ORT и пустой API-ключ. Остальные параметры берутся из Config.

Сначала можно посмотреть точный состав и адрес сервера без записи файлов и отправки изображений:

```powershell
venv/Scripts/python.exe scripts/test_images.py run --config D:/Documents/apps/ImageLocalizationTool/data/settings.json --output output/review-my-run --dry-run
```

Автономный запуск всего набора:

```powershell
venv/Scripts/python.exe scripts/test_images.py run --config D:/Documents/apps/ImageLocalizationTool/data/settings.json --output output/review-my-run --background
```

Без `--background` команда ждёт завершения и показывает прогресс в консоли: `[номер/всего]`, имя файла, процент и стадию, длительность и итог страницы, общие счётчики. Во время ожидания раз в 30 секунд выводится текущая стадия и прошедшее время. В фоне окно не появляется, такой же вывод записывается в `runner.log`; закрытие чата не является командой остановки. Завершение видно в `summary.json` и последнем событии `run_finished`. Скрипт не обходит разрешения/ограничения среды на сетевой доступ. Если ОС запрещает остановку дерева зависшей страницы, очередь останавливается со статусом `stop_failed`, чтобы не запускать следующую страницу одновременно с оставшимся процессом.

Выборочная регрессия использует тот же сценарий и формат:

```powershell
venv/Scripts/python.exe scripts/test_images.py run --config D:/Documents/apps/ImageLocalizationTool/data/settings.json --output output/review-subset --include 3930955.png --include 3419871.png --include "sound-ref/*" --background
```

`--images-root` меняет каталог исходников (по умолчанию `test-img`). Повторяемые `--include`/`--exclude` — glob относительно него. Обход рекурсивный и отсортированный; маски (`mask`, включая прежнюю опечатку `msak`) и папка `html` исключаются автоматически. Изображения с одинаковым именем в разных папках получают разные id.

## Явный список и наблюдение

### Явный список локальных файлов

Передайте несколько путей через `--images`, чтобы обработать только их, в том числе из разных папок вне `test-img`:

```powershell
venv/Scripts/python.exe scripts/test_images.py run --config D:/Documents/apps/ImageLocalizationTool/data/settings.json --output output/review-selected --images "D:/Documents/Projects/tools/image-localization-tool/test-img/3930955.png" "D:/Documents/Projects/tools/image-localization-tool/test-img/26617.png"
```

В этом примере прогресс виден прямо в консоли. Добавьте `--background`, если нужен фоновый режим.

Длинный список удобнее сохранить в TXT (один путь на строку) или JSON (массив строк) и передать файлом:

```powershell
venv/Scripts/python.exe scripts/test_images.py run --config D:/Documents/apps/ImageLocalizationTool/data/settings.json --output output/review-list --list-file output/images-to-test.txt
```

Пример TXT:

```text
D:/Documents/Projects/tools/image-localization-tool/test-img/3930955.png
D:/Documents/Projects/tools/image-localization-tool/test-img/26617.png
```

В TXT допускаются пустые строки, кавычки вокруг пути и UTF-8 BOM. JSON-файл должен содержать массив строк; Windows-пути в JSON удобнее писать с `/` или экранированными `\\`.

Относительные пути из TXT/JSON разрешаются от папки самого списка; в `--images` — от текущей рабочей папки. Можно повторять и сочетать `--images` и `--list-file`. Сначала берутся аргументы, затем файлы списков. Порядок первого появления сохраняется, повторы удаляются. Отсутствующие файлы и неподдерживаемые форматы отклоняются до обработки. Маски исключаются автоматически; соседние файлы в очередь не добавляются. Поддерживаются локальные файлы, не HTTP-ссылки. Параметры `--include`/`--exclude` могут дополнительно фильтровать выбранный список.

Наблюдение за фоновым прогоном из PowerShell:

```powershell
Get-Content output/review-list/runner.log -Tail 20 -Wait
```

## Продолжение и ошибки

Повторите исходную команду с теми же параметрами и `--output`. Готовые PNG проверяются по хешу и не отправляются повторно. Незавершённая страница запускается снова. Чтобы повторить страницы с ошибками, добавьте `--retry-errors`.

Изменение состава/содержимого исходников, кода, шаблона, эффективных настроек или параметров прогона требует нового `--output`: смешивать результаты разных условий нельзя. Изменение только API-ключа не влияет на профиль: ключ не используется. Предел страницы задаёт `--page-timeout` (по умолчанию 1800 секунд). Авария/тайм-аут отражаются в отчёте, следующие страницы продолжаются. Один каталог защищён блокировкой ОС, освобождаемой после завершения/аварии.

Коды завершения синхронной команды: `0` — все обработаны; `1` — ошибки страниц; `2` — ошибка запуска/условий; `130` — прерывание. Фоновая команда возвращает успешный запуск, а результат обработки проверяется отдельно:

```powershell
venv/Scripts/python.exe scripts/test_images.py status --output output/review-my-run
```

## Галерея и отчёты

Откройте `index.html` из каталога прогона. Только итоговые изображения, оценка 1–5 и комментарий. Верхняя часть уходит при прокрутке; кнопки JSON есть сверху и снизу. Оценки сохраняются в текущем браузере. Для передачи нажмите «Скачать оценки JSON»; при запрете хранилища браузера скачайте JSON до закрытия страницы.

- `manifest.json`: версия формата, run_id, исходники/хеши, снимок Config без ключа, хеши кода, параметры и версия Python.
- `report.json`: та же версия и run_id, состояния страниц, времена, движки, предупреждения, ошибки, хеши результатов.
- `summary.json`: общий статус, счётчики, длительность и предупреждения/ошибки по страницам.
- `events.jsonl`: события запуска, стадий, завершения и прерывания с временем UTC.
- `<id>/`: `result.png`, `regions.json`, `record.json`, `process.log`, `debug/`.
- Экспорт оценок: `schema_version`, `run_id`, `exported_at`, `images` с именем, хешами, `rating`, `comment`, `updated_at`. Неоценённые — `rating: null`.

Шаблон общий: `scripts/templates/review_gallery.html`. Перестроить галерею без обращения к моделям и серверу:

```powershell
venv/Scripts/python.exe scripts/test_images.py gallery --output output/full-review-20261114
```

Команда поддерживает прежний список в `report.json`, сохраняет его id и ключ оценок `ilt-review:<run_id>`. Старые вычислительные прогоны не продолжаются новым инструментом: для нового распознавания нужен новый каталог. Форматы отчётов новых прогонов всегда версии 1.

Сценарий воспроизводим; ответы LLM могут отличаться между запусками. `done` означает завершение обработки, а не гарантию качества. Предупреждения (например, недоступная вычитка) сохраняются. Автоматический выбор лучшего результата, изменение алгоритмов и визуальная оценка в сценарий не входят. Исходники, отчёты и оценки локальные, в git не добавляются.

## Проверка инструмента

```powershell
venv/Scripts/python.exe -m pytest tests/unit/test_test_images.py -q
node tests/js/test_review_gallery.mjs
```

Проверка реального тайм-аута требует права остановки собственного дерева процессов (в ограниченной песочнице Windows это право может отсутствовать).

Для реального smoke используйте один небольшой исходник с `--include`, затем повторите ту же команду: повторных событий `page_started` и сетевой обработки быть не должно.
