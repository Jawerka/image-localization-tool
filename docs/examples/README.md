# Примеры перевода для README

Исходники (`sources/`), результаты (`translated/`) и сравнения полного размера (`comparisons/*-full.jpg`) в git не входят. Их восстанавливает `scripts/update_readme_examples.py`. В репозитории остаются превью, `regions/`, `runs/` и `manifest.json`.

Четыре фиксированных изображения обрабатываются основным `PagePipeline.process`, тем же, который использует программа. Исходный язык: китайский, корейский, японский или английский; целевой — русский. Включены адаптивное оформление, поиск пропущенных надписей и перевод SFX (`replace`). Остальные параметры берутся из стандартного `Config` и явных настроек в `manifest.json`.

## Честность демонстрации

Сохранены первые завершённые сквозные прогоны выбранных изображений. OCR, перевод, маски и оформление не правились вручную. Японские и английские тексты получены независимо из соответствующих картинок: текст опубликованного русского перевода не использовался. Сравнение добавляет только внешние подписи, авторство и уменьшенную копию для README. Полный размер сравнения также JPEG; неизменённые пиксели результата программы находятся в `translated/*.png`.

Технических предупреждений в этих четырёх запусках нет, но ошибки видны: японская реплика дублируется, английская страница содержит ложное «Привет», историческая китайская страница переведена и очищена лишь частично. Формулировки перевода местами неточны. Это демонстрация результата, не обещание полного перевода или независимая оценка точности. Знания модели об известных произведениях исключить нельзя.

## Как обновить после улучшения алгоритмов

1. Сохранить те же `sources/` и `manifest.json`: в нём указаны страницы, авторство, URL скачивания, SHA-256 исходных файлов, обрезка и настройки. Не менять входные страницы ради более красивого результата. При осознанной замене источника отдельно проверить права, обновить кредиты, хеш и описание в README.
2. Подготовить обычное окружение проекта и модели (`requirements.txt`, `scripts/setup_models.py`). Указать свой OpenAI-совместимый сервер с vision-моделью. Ключ при необходимости — только в переменной `ILT_LLM_API_KEY`; адрес и ключ не записываются в публичную конфигурацию примеров.
3. Запустить из корня репозитория:

   ```powershell
   python scripts/update_readme_examples.py --render --llm-url http://localhost:8080/v1 --llm-model YOUR_VISION_MODEL
   ```

   Без `--llm-model` модель определяется через `/v1/models`. `--models-dir` задаёт каталог моделей, по умолчанию `models/` в корне репозитория. Все страницы и запросы обрабатываются последовательно. Для одного примера добавить `--case chinese`, `korean`, `japanese` или `english`. Каждая команда `--render` заново выполняет распознавание, перевод, очистку и вёрстку; старые переводы и маски не переиспользуются. Технические повторы внутри обычного пайплайна сохраняются.
4. Проверить оригиналы и все результаты без сети и загрузки моделей:

   ```powershell
   python scripts/update_readme_examples.py --verify
   ```

5. Просмотреть **все четыре** сравнения в полном размере. Проверить пропуски, лишние надписи, остатки букв, переполнения и смысл перевода; обновить замечания в корневом README и этом файле. Не исправлять изображения вручную и не выбирать лучший из скрытых повторных прогонов. При повторе из-за сбоя объяснить причину в изменении документации. Закоммитить превью, `regions/`, `runs/` и документацию. Исходники, результаты и полные сравнения остаются локальными.

`runs/*.json` содержит дату, модель, версию кода, хеш генератора, явные настройки, шрифты, движки, время, предупреждения и хеши артефактов. Поле `commit` указывает на `c498ba2` из прежней истории; его нельзя подменять новым корнем. Как получить этот срез — [docs/HISTORY.md](../HISTORY.md). `regions/*.json` — распознанный текст, русский перевод, координаты и оформление для проверки. Полный промежуточный вывод остаётся в игнорируемом `output/readme-examples/`. Хеши позволяют обнаружить изменение файлов, но не доказывают отсутствие ручных правок сами по себе.

При новой модели, версии библиотек, других системных шрифтах или аппаратном обеспечении результат может отличаться. В текущих прогонах свободный текст использует установленные Windows Impact/Comic Sans Bold Italic, облачка — комплектный Heroika. Системные шрифты не включены в репозиторий. LLM не гарантирует побитовую воспроизводимость; задача набора — повторяемая проверка тех же входов через актуальную программу.
