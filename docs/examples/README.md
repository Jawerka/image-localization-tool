# Примеры перевода для README

Исходники (`sources/`), результаты (`translated/`) и сравнения полного размера (`comparisons/*-full.jpg`) в git не входят. Их обновляют общая очередь `scripts/test_images.py run` и импорт результатов через `scripts/update_readme_examples.py`. В репозитории остаются превью, `regions/`, `runs/` и `manifest.json`.

Четыре фиксированных изображения обрабатываются основным `PagePipeline.process` через стандартную тестовую очередь, тем же путём, который использует программа. Языки исходников — китайский, корейский, японский и английский; в свежем прогоне передаётся `source_lang: auto`, целевой — русский. Включены адаптивное оформление, поиск пропущенных надписей и перевод SFX (`replace`). Остальные параметры берутся из стандартного `Config` и явных настроек в `manifest.json`.

## Честность демонстрации

Примеры обновлены 2026-11-15 на коде `55dc35c`, модель `qwen36-27b-mtp-q6k-2x5060ti`, очередь `run-d8f808a6`. Все четыре страницы завершены за 672 секунды без ошибок обработки. Английский пример после пользовательской проверки повторён в очереди `run-92bf6496` за 145 секунд: исправлены склейка внешнего текста с облачком и неполная маска угловатого звука. Первый повтор обнаружил частичную маску; следующий потребовал ограничить добор букв белым фоном после срабатывания регрессионного теста защиты рисунка. Сохранён результат финального прогона, а не выбранный лучший перевод из повторов. Остальные три результата не менялись. OCR, перевод, маски и оформление не правились вручную. Японские и английские тексты получены независимо из соответствующих картинок: текст опубликованного русского перевода не использовался. Сравнение добавляет только внешние подписи, авторство и уменьшенную копию для README. Полный размер сравнения также JPEG; неизменённые пиксели результата программы находятся в `translated/*.png`.

Все четыре сравнения просмотрены. Корейский пример содержит три переведённые подписи, явных наложений или остатков букв при просмотре не замечено. В английском остаются ложное «Привет» и неточные формулировки; верхняя мысль теперь переведена отдельно, нижняя реплика помещена в своё облачко, звуковая надпись очищена целиком. Японский пример плохо размещает длинный русский текст в узких исходных полях: есть выход за границы и неудачные повороты. Китайский основной верхний блок заменён русским текстом, но часть иероглифов и подписи остались; исходная вертикальная композиция не сохранена.

В отчётах китайского примера — 11 предупреждений, включая неподтверждённые дополнительные рамки и исчерпанный бюджет их проверки; японского — два, включая переполнение регионов `[1, 4, 5, 7, 8]`. У английского и корейского предупреждений нет, что само по себе не подтверждает качество. Формулировки перевода местами неточны. Это демонстрация результата, не обещание полного перевода или независимая оценка точности. Знания модели об известных произведениях исключить нельзя.

## Как обновить после улучшения алгоритмов

1. Сохранить те же `sources/` и `manifest.json`: страницы, авторство, хеши и фиксированную обрезку. Не менять входы ради более красивого результата.
2. Подготовить окружение и модели. Указать файл настроек своего vision/LLM-сервера. Ключ стандартный сценарий не использует; адрес сервера остаётся в локальном каталоге `output/`.
3. Подготовить четыре PNG и конфигурацию. Для каждого нового прогона выбрать новую папку:

   ```powershell
   venv/Scripts/python.exe scripts/update_readme_examples.py --prepare-run output/readme-examples-new --config path/to/settings.json
   venv/Scripts/python.exe scripts/test_images.py run --config output/readme-examples-new/config.json --images-root output/readme-examples-new/inputs --output output/readme-examples-new/run --dry-run
   ```

   Подготовка проверяет хеши оригиналов и применяет только обрезку из манифеста. Настройки сервера и моделей берутся из указанного файла; профиль примеров — из манифеста. Исходный язык определяется автоматически. Адрес, состав и разрешение на передачу изображений нужно проверить до обработки.
4. Запустить одну фоновую последовательную очередь:

   ```powershell
   venv/Scripts/python.exe scripts/test_images.py run --config output/readme-examples-new/config.json --images-root output/readme-examples-new/inputs --output output/readme-examples-new/run --background
   venv/Scripts/python.exe scripts/test_images.py status --output output/readme-examples-new/run
   ```

   Открыть `output/readme-examples-new/run/index.html`: там прогресс, ETA и новые результаты. Успешный запуск фонового процесса не означает завершение. При изменении кода, настроек или входов нужна новая папка; продолжение без изменений — та же команда. Подробности — [стандартный сценарий](../TEST_IMAGE_RUNNER.md).
5. После завершения импортировать результаты и проверить артефакты без повторного OCR:

   ```powershell
   venv/Scripts/python.exe scripts/update_readme_examples.py --import-run output/readme-examples-new
   venv/Scripts/python.exe scripts/update_readme_examples.py --verify
   ```

   Импорт проверяет входы и хеши готовых PNG, переносит результаты без изменения пикселей, обновляет регионы, отчёты и сравнения с внешними подписями. `--case chinese|korean|japanese|english` ограничивает подготовку или импорт одним примером. Старый `--render` больше не запускает отдельный вычислительный сценарий.
6. Просмотреть все четыре сравнения в полном размере. Проверить пропуски, лишние надписи, остатки букв, переполнения и смысл перевода; обновить замечания в README и этом файле. Не править изображения вручную и не выбирать лучший из скрытых повторов. При повторе из-за сбоя объяснить причину. В git входят превью, `regions/`, `runs/`, манифест и документация; оригиналы, переведённые PNG, полные сравнения и каталог очереди остаются локальными.

`runs/*.json` содержит дату, модель, версию кода, хеш генератора, явные настройки, исходный язык произведения и фактически переданный `effective_source_lang`, идентификатор очереди, движки, время, предупреждения и хеши артефактов. Серверные адреса, локальные пути и ключи в публичные отчёты не переносятся. `regions/*.json` содержит распознанный текст, перевод, координаты и оформление. Срез старых примеров `c498ba2` относится к прежней истории — [как получить старый код](../HISTORY.md).

При другой модели, библиотеках, шрифтах или оборудовании результат может отличаться. LLM не гарантирует побитовую воспроизводимость. Набор проверяет те же входы через актуальную программу; четыре демонстрации не заменяют оценку произвольных страниц.
