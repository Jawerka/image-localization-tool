# Расширение браузера

MV3 «Image Localization Tool». Версия сборки берётся из версии приложения. Пользователь сам выбирает картинку: кнопка в углу, пункт «Перевести изображение» или Alt+Shift+T. Перевод обычной картинки становится её содержимым. Если подмена невозможна, тот же результат показывается наложением. Массового перевода страницы нет.

Контент-скрипты на `http://*/*`, `https://*/*` и `file:///*` (`document_idle`, все фреймы) не меняют разметку страницы. Кнопка живёт в shadow на `popover` и не стоит рядом с картинкой. Магазины Ozon исключены: страница не показывает фото, пока скрипт внедрён. Для `file://` нужно разрешение браузера.

## Кнопка

Пока курсор не на картинке, на странице нет элементов расширения. После короткого покоя (по умолчанию 220 мс) в свободном углу появляется кнопка. Уход прячет её примерно через 300 мс, чтобы курсор успел дойти до кнопки. Картинка ищется сквозь прозрачные слои. Углы: правый верхний, левый верхний, правый нижний, левый нижний — первый, где нет кнопки, ссылки или видео сайта.

Кнопка не показывается при зажатой мыши, выделении, фокусе в поле ввода, полноэкранном видео, на декоративных и слишком маленьких картинках и на доменах из `hoverDisabledSites`. Клик не активирует ссылку вокруг картинки. Принимаются только действия пользователя.

Та же кнопка показывает очередь, процент и подпись этапа: «Ищем текст», «Распознаём», «Переводим», «Стираем оригинал», «Вписываем перевод», «Из кэша». Если служба прислала `eta_ms`, видно оставшееся время. После готовности короткое подтверждение, затем кнопка скрывается. Новое наведение открывает «Сравнить» (удержание и Alt), «Копировать», «Сохранить», «Перевести заново», «Убрать» и «Не показывать на этом сайте». Ошибка раскрывает текст, код и «Повторить» / «Сохранить логи».

Правила отбора картинки прежние: файл длиннее 180 px, на экране длинная сторона не меньше настройки (160 px) и короткая не меньше 80 px, не `aria-hidden`, не `presentation`/`none`, не значок в шапке.

Позиция держится якорём браузера, если он есть. Иначе — по прокрутке и изменению размера, без постоянного цикла кадров. В диалоге хост переносится внутрь него.

## Пульт и настройки

Значок открывает пульт: точка связи, язык, переключатель кнопки на этом сайте, число переводов вкладки, «Показать все оригиналы», «Убрать все», ручной выбор, настройки и сохранение журнала при ошибках. Без сопряжения пульт предлагает подключиться.

Настройки — карточки «Подключение», «Кнопка», «Оформление», «Сигнал», «Диагностика». Код вводится шестью ячейками, связь проверяется при открытии. Тема `system` / `light` / `dark` применяется сразу. Звук по готовности картинки выключен, пока пользователь не включит `chimeOnReady`.

Бейдж значка — число активных задач вкладки, при ошибке без активных задач — «!». «Сохранить перевод» в контекстном меню виден только если перевод есть.

## Сборка

`python scripts/make_extension_icons.py` пишет PNG 16/32/48/128. `python scripts/build-extension.py` копирует их и исходники, без `content.js` и без панели.

Контент-скрипты: `chime.js`, `native-swap.js`, `button-model.js`, `log.js`, `inline-content.js`, `safe-content.js`.

Chromium: service worker-модуль, `offscreen`, `downloads`, `declarativeNetRequest` и `declarativeNetRequestWithHostAccess`. Firefox собирается без `offscreen`; вживую не заявлен.

Команда `translate-hovered`, сочетание по умолчанию Alt+Shift+T.

## Сопряжение

`storage.local`:

- `serverUrl`, `token`, `targetLang` — как раньше. Пустой адрес становится `http://127.0.0.1:8765`. Языки: `ru`, `en`, `uk`.
- `buttonEnabled` — кнопка включена, по умолчанию да.
- `hoverDelayMs` — задержка появления, по умолчанию 220.
- `hoverMinLong` — минимальная длинная сторона, по умолчанию 160.
- `hoverDisabledSites` — домены без кнопки.
- `theme` — `system`, `light` или `dark`.
- `chimeOnReady` — звук по готовности картинки, по умолчанию выключен. `chimeId` и `chimeVolume` задают звук и громкость.
- `logVerbose` — подробный журнал.

При установке и обновлении удаляются устаревшие `interactionMode` и `autoSites`. Список исключённых доменов сохраняется.

«Сопрячь»: `POST /v1/pair`. «Проверить связь»: `GET /v1/health`. Статусы: «сопряжено», «связь есть», «сервер не готов», «сервер не найден», «ключ отозван», «очередь заполнена», «ошибка сервера » и код.

Перед загрузкой расширение узнаёт лимит сервера через `/v1/health` и проверяет размер всего multipart-запроса. Новый сервер принимает до 64 МиБ включительно; для старого ответа без `max_body_bytes` действует 20 МиБ. При превышении передача не начинается, сообщение указывает лимит. Оригинал не уменьшается и не сжимается. Ответ 413 показывает причину сервера (в том числе ограничение 40 млн пикселей) либо сообщение о превышении размера. В журнале сохраняются код отказа, HTTP-статус и маршрут без ключа сопряжения. Локальный `TypeError` больше не считается отсутствием сервера.

## Задачи

Фон держит очередь до 2 задач. `POST /v1/translate`, затем `GET /v1/jobs/{id}` примерно раз в 600 мс. Ответ дополнительно содержит `label`, `elapsed_ms`, `eta_ms`; старые поля на месте. Страница получает ход через порт `ilt-page`, а не своим циклом опроса.

Незавершённая задача с `remoteId` лежит в `storage.session` и продолжается после перезапуска фона. Готовый результат кэшируется в `CacheStorage` `ilt-results` по адресу и языку, примерно до 300 МБ.

Загрузка картинки: `fetch` с cookie, при 401/403 — сессионный Referer страницы только для запроса расширения, затем повтор. `blob:` и `data:` читает страница и передаёт байты. Прочие форматы приводятся к PNG. Отказ загрузки несёт код `E_DOWNLOAD_<статус>`.

Ключ задачи: адрес страницы без фрагмента, перевод строки, адрес картинки. `force` и `fresh=1` прогоняют пайплайн заново.

## Журнал

Кольцо около 2000 записей в `storage.local` (`iltLog`). Секрет сопряжения не пишется. У адресов срезаются query и fragment. «Сохранить логи» есть в настройках, пульте и меню ошибки. Файл `ilt-extension-log-YYYYMMDD-HHMM.json` содержит окружение, настройки без токена, ответ `/v1/health`, сводку задач и записи. Рядом «Копировать», «Очистить» и «Подробный журнал».
