# Настольное приложение

Окно поверх пайплайна v2. Версия читается из `src/app/__init__.py` (`__version__`, сейчас `1.0.0`) и уходит в `GET /api/bootstrap`. Качество на произвольных страницах то же, что у CLI: см. [README.md](../README.md).

Точка входа — `python -m src.app` (`src/app/__main__.py` → `src/app/desktop.py`). Команда `python src\main.py` по-прежнему гоняет пайплайн из консоли, без этого окна.

## Запуск и режимы

```powershell
python -m src.app
python -m src.app --browser
python -m src.app page.png папка
python -m src.app page.png --browser папка
```

Флаг `--browser` можно ставить и после путей. Позиционные аргументы — файлы и папки страниц. Непустой список при старте уходит в `POST /api/drop`.

Без флага поднимается локальный HTTP и окно pywebview (`gui="edgechromium"`, `private_mode=True`: настройки интерфейса живут в `settings.json`). Заголовок — «Image Localization Tool». Ширина и высота берутся из настроек, иначе 1280×800; минимум 1100×700. Координаты подставляются, только если они записаны. При закрытии геометрия пишется в настройки. Если идёт обработка, окно спрашивает «Идёт обработка. Закрыть приложение?».

На Windows перед окном проверяется Microsoft Edge WebView2 Runtime (запись `pv` в реестре EdgeUpdate). Если среды нет или окно не стартовало, показывается сообщение с просьбой установить Runtime, процесс завершается с кодом 1.

`--browser` поднимает тот же сервер и открывает системный браузер по адресу `http://127.0.0.1:<порт>/?k=<token>`. Нативные диалоги окна в этом режиме не подключаются: выбор файлов, папки и папки экспорта из интерфейса ничего не возвращает. Пути по-прежнему можно передать аргументами запуска.

Один экземпляр. В корне данных лежит `instance.json` с `pid` и портом короткого TCP на `127.0.0.1` (это не порт HTTP). Второй запуск, если процесс жив и соединение удалось, отправляет одну строку `{"paths":[...]}` и выходит. Первый экземпляр добавляет пути через `POST /api/drop` и на Windows выводит окно вперёд. Мёртвая запись или обрыв соединения — этот запуск становится первым.

Журнал — `logs/app.log` (ротация при старте). В сборке без консоли stdout и stderr пишутся в тот же файл. В окне пункт журнала открывает этот путь.

## Где лежат данные

Каталоги создаются при записи, не при импорте модуля.

Если рядом с программой есть каталог `data`, режим портативный: настройки, проекты, кэш и лог лежат внутри него. «Рядом» — папка exe в сборке (`sys.frozen`) или корень репозитория при запуске из исходников.

Иначе на Windows:

| Что | Путь |
|-----|------|
| Настройки | `%APPDATA%\ImageLocalizationTool\settings.json` |
| Проекты, кэш, лог, `instance.json` | `%LOCALAPPDATA%\ImageLocalizationTool\` |

На других ОС и настройки, и остальное — в `~/.image-localization-tool/`.

В корне данных: `projects/`, `logs/`, `cache/`, `instance.json`. Каталог `cache/` задан в `src/app/paths.py`; текущий код приложения туда не пишет.

Файл настроек — JSON схемы 1. Битый файл переименовывается в `settings.json.bad` (дальше `.bad-2`, …), приложение стартует с значениями по умолчанию. Адрес LLM в настройках окна по умолчанию пустой: значение из `config.json` CLI сюда не копируется.

Ключ API в JSON не пишется. Он лежит в keyring: служба `ImageLocalizationTool`, имя `llm`. Пустая строка в `set_api_key` удаляет запись. `PUT /api/settings` поля `api_key` и `schema` пропускает. `POST /api/settings/secret` с непустым `api_key` пишет ключ в keyring; пустая строка в этом запросе запись не меняет.

В настройках есть строка `glossary_path` — путь к файлу глоссария. Глоссарий открытого проекта хранится в проекте и правится в окне. Экспорт пишет PNG или JPG (`rename`, `overwrite`, `skip`). Формата CBZ нет.

Поле `sfx_mode` — `skip` или `replace`, по умолчанию `skip`. Рядом хранится `translate_sfx`: `true` только при `replace`. В старом JSON без `sfx_mode` флаг `translate_sfx: true` читается как `replace`, отсутствие флага или `false` — как `skip`. Если `sfx_mode` уже есть, он главнее: значение вне этих двух становится `skip`, и `translate_sfx` выравнивается по нему.

## Проект на диске

Корень — `projects/<id>/`, идентификаторы проекта и страницы — 8 шестнадцатеричных символов. Оригинал картинки не копируется: в `project.json` хранится абсолютный `source_path`.

```
projects/<id>/
├── project.json
└── pages/<id>/
    ├── page.json
    ├── auto.json          # после перевода
    ├── thumb.jpg
    ├── mask_auto.png
    ├── clean.png
    └── result.png
```

`project.json`: `id`, `name`, `source_lang`, `target_lang`, `created`, список `pages` (`id`, `source_path`, `name`).

`page.json`: `status`, `progress`, `stage`, `error`, `warnings`, `document`. Статусы: `idle`, `queued`, `running`, `done`, `edited`, `offline`, `error`.

`auto.json` — снимок документа после автоматического перевода, до ручных правок. Сброс страницы читает его и заново применяет очистку. Пока перевода не было, файла нет.

В проект попадают PNG, JPG/JPEG, BMP, TIFF верхнего уровня папки (без обхода подкаталогов). Файлы, в имени которых есть `-mask`, пропускаются. Повтор того же `source_path` не добавляется. Удаление страницы из проекта стирает её каталог и не трогает файл оригинала.

ZIP, CBZ, CBR/RAR, CB7/7Z и CBT/TAR распаковываются в каталог `imports` проекта. Изображения берутся не глубже пяти вложенных папок. Архив без изображений не создаёт проект: ответ — «переводить нечего». CBR, внутри которого zip, открывается как zip. Для настоящего RAR нужен 7-Zip или UnRAR.

Картинки, которые пишет приложение: `mask_auto.png`, `clean.png`, `result.png`, `thumb.jpg`. Вид `original` в API — это сам `source_path`, не копия в каталоге страницы.

## HTTP API

Сервер слушает только `127.0.0.1` и случайный порт. Статика — каталог `web/` (корень — `index.html`). Каталог `mockups` не отдаётся. Страница открывается как `/?k=<token>`: в ответ ставится cookie, редиректа нет.

Все ответы `/api/*`, кроме `POST /api/session`, требуют cookie. Тело JSON — объект, не больше 8 МиБ. У `PUT /api/project/glossary` тело может быть и JSON-списком. Пути к файлам из JSON читают `POST /api/drop` и `POST /api/import`. Папку экспорта задаёт диалог; поле `dest` подставляется, только если это та же папка.

Чужой метод — 405, нет объекта — 404, битый JSON — 400, конфликт `base_version` — 409 с текущим `document`.

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/api/bootstrap` | Версия, настройки, предупреждение схемы, проект, страницы, статус LLM, готовность моделей, `busy`, недавние проекты, `has_api_key`, пути `settings` и `data` |
| GET | `/api/pages` | Всегда 404. Список страниц приходит в bootstrap и в ответах, которые меняют проект |
| GET | `/api/pages/{id}` | Строка страницы и документ |
| PUT | `/api/pages/{id}/document` | Запись документа. Нужны `base_version` и `document`. При плане `typeset` или `clean` страница становится `edited` и уходит в очередь |
| POST | `/api/pages/{id}/reset` | Вернуть документ из `auto.json` и заново очистить |
| POST | `/api/pages/{id}/action` | Действие региона: `recognize`, `retranslate`, `shorten`. Нужен `region_id` |
| POST | `/api/pages/{id}/preview-region` | Предпросмотр вёрстки региона. Нужен `region_id`. Ответ `image/png`, заголовки `X-Offset-X` и `X-Offset-Y` |
| POST | `/api/pages/{id}/regions/{region_id}/sfx-style` | Подобрать стиль звука и записать его в регион. Страница становится `edited` |
| GET | `/api/pages/{id}/image/{kind}` | Картинка: `original`, `result`, `clean`, `mask`, `thumb` |
| POST | `/api/jobs/translate` | `scope`: `page` (нужен `page_id`) или `all` |
| GET | `/api/jobs` | Очередь: `paused`, есть ли незаконченные задания (`unfinished`), `restored` |
| POST | `/api/jobs/cancel` | Очистить очередь целиком и снять паузу. Текущее задание останавливается. Страницы в `queued` и `running` возвращаются в `idle` |
| POST | `/api/jobs/pause` | Пауза: новые задания воркеру не отдаются. Уже отданное может закончиться |

| POST | `/api/jobs/retry-errors` | Снова поставить задания со статусом `error` |
| POST | `/api/jobs/export` | Экспорт в папку, выбранную диалогом. Поле `content`: `result` (перевод), `clean` (очищенная страница после ретуши маски) или `both` (перевод и файл с суффиксом `-clean`). Формат `png` или `jpg`, качество JPEG, конфликт `rename` / `overwrite` / `skip`. Список `page_ids` необязателен |
| POST | `/api/dialog/directory` | Диалог папки экспорта. Отмена: `cancelled` |
| POST | `/api/dialog/files` | Диалог файлов и добавление в проект |
| POST | `/api/dialog/folder` | Диалог папки и добавление картинок верхнего уровня |
| POST | `/api/dialog/log` | Показать `logs/app.log` |
| POST | `/api/dialog/reveal` | Показать папку последнего экспорта или каталог проекта |
| PUT | `/api/settings` | Записать известные поля настроек. `api_key` и `schema` игнорируются |
| POST | `/api/settings/secret` | Записать непустой `api_key` в keyring |
| POST | `/api/llm/check` | Проверить адрес LLM. В ответе `vision` всегда `false` |
| GET | `/api/models` | Есть ли на диске `detector`, `lama` и `font` (`present`, `path`) |
| POST | `/api/models/download` | Скачать `kind`: `detector` и `lama` в каталог моделей, `font` в `fonts` рядом с программой. Ответ 202 уходит после окончания загрузки. По ходу шлётся `model.progress` |
| GET | `/api/fonts` | Каталог шрифтов: `id`, `family`, `category`, `cyrillic` |
| GET | `/api/fonts/{id}/preview` | Образец `image/png`. Query `text` необязателен, по умолчанию «Привет», не длиннее 40 символов |

| POST | `/api/import` | Импорт `path`: картинка, папка или архив (zip, cbz, cbr, rar, cb7, 7z, cbt, tar). `chapter_mode` — `subdir` (по умолчанию) или `flat`. `recursive` для папки. Изображения в архиве — не глубже 5 папок. Нет изображений — ошибка, проект не создаётся |
| GET | `/api/project/glossary` | Глоссарий открытого проекта |
| PUT | `/api/project/glossary` | Заменить глоссарий. Тело — JSON-список или объект с `glossary` либо `entries` |
| GET | `/api/project/styles` | Стили проекта. Пустая библиотека отдаёт три стиля по умолчанию («Диалог», «Крик», «SFX») и на диск не пишется |
| PUT | `/api/project/styles` | Заменить стили. Нужен список `styles` |
| GET | `/api/remote/status` | Сводка слушателя: `enabled`, `port`, `addresses`, `pairing_code`, `devices`, `recent`, `clients`. Слушатель не поднят — пустая сводка |
| POST | `/api/remote/pair-code` | Новый код из 6 цифр. Слушатель выключен — 409 «Доступ по сети выключен» |

| POST | `/api/project/open-recent` | Открыть проект по `id` |
| POST | `/api/session` | Обменять `token` из тела на cookie. Прежняя cookie не нужна |
| GET | `/api/events` | Поток SSE. Нужна cookie |

## Доступ по сети

Удалённый API — отдельный слушатель, не порт окна. По умолчанию он выключен: в настройках `remote_enabled` — false. Локальный интерфейс по-прежнему слушает только `127.0.0.1`.

```powershell
python -m src.app --headless --remote
```

`--headless` не открывает окно. Без `--remote` процесс печатает «Удалённый доступ выключен. Запустите: python -m src.app --headless --remote» и завершается. Вместе флаги включают LAN-слушатель на этот запуск, даже если в настройках он выключен, и подключают пайплайн. Адрес и порт LAN берутся из `remote_bind` и `remote_port` (по умолчанию `0.0.0.0` и `8765`). Флагов адреса и порта в командной строке нет. Локальный HTTP для кода сопряжения слушает `127.0.0.1:8766`; токен сессии пишется в `data/session.token` (в портативном режиме) с правами `0600`.

С окном (`python -m src.app` или с `--browser`) слушатель стартует по `--remote` или когда `remote_enabled` уже true. Тогда к нему подключается пайплайн. Смена `remote_enabled` в настройках действует со следующего запуска.

Код подключения — шесть цифр, живёт 300 секунд, одно использование. Новый вызов сменяет ещё не использованный код. Его выдаёт локальный `POST /api/remote/pair-code` (нужна cookie сессии: сначала `POST /api/session` с токеном из `session.token`). Устройство отдаёт код на `POST /v1/pair` и получает токен один раз. В `remote_devices` остаются `id`, `name`, `token_hash` и `created`; сырой токен туда не пишется. Отозвать устройство — `POST /api/remote/revoke` с полем `id`. Уже записанные устройства по токену проходят.

В настройках, раздел «Доступ по сети», текст предупреждения: «Брандмауэр Windows может блокировать порт, пока для программы не разрешены входящие подключения в частной сети. В локальной сети страницы открываются по обычному HTTP, без шифрования.» По умолчанию слушатель садится на `0.0.0.0`.

Картинки с устройств попадают в проект «Входящие»: он создаётся, если проекта с таким именем ещё нет.

### Контракт /v1

`GET /v1/health` и `POST /v1/pair` без токена. Остальные маршруты — заголовок `Authorization: Bearer`. Чужой токен — 401. На одно устройство не больше 30 таких запросов за 60 секунд, иначе 429.

Тело не больше 20 МиБ (20 × 1024 × 1024 байт ещё принимается). Картинка больше 40 000 000 пикселей — 413. Незавершённых заданий (`queued` и `running`) не больше 8; сверх того `POST /v1/translate` отвечает 429. Попадание в кэш слот не занимает: ответ всё равно 202, задание сразу `done`, PNG лежит на `GET /v1/jobs/{id}/result`. Идентификатор задания — hex. Чужое задание для этого устройства — 404.

`Origin` с префиксом `chrome-extension://` или `moz-extension://` получает CORS: в `Access-Control-Allow-Origin` уходит исходная строка, методы `GET, POST, DELETE`, заголовки `Authorization, Content-Type, X-Source-Lang, X-Target-Lang`, плюс `Vary: Origin`. `OPTIONS` с таким Origin — 204, без него — 403. Другой Origin заголовков CORS не получает.

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/v1/health` | `version` (строка `dev`) и `ready`: слушатель принял сокет |
| POST | `/v1/pair` | Тело: `code`, необязательное `name`. Ответ `token` или 401 «Неверный код» |
| POST | `/v1/translate` | Всегда 202 и `job_id`. Тело — байты картинки или `multipart/form-data` с полем `file`. Языки — поля `source_lang` и `target_lang` либо заголовки `X-Source-Lang` и `X-Target-Lang` |
| GET | `/v1/jobs/{id}` | `id`, `status` (`queued`, `running`, `done`, `error`), `stage`, `position`, `error` |
| GET | `/v1/jobs/{id}/result` | `image/png`, если задание `done`. Иначе 409, нет задания — 404 |
| DELETE | `/v1/jobs/{id}` | Удалить задание своего устройства. Ответ 204 |

## События SSE

`GET /api/events`, `Content-Type: text/event-stream`. Каждые 15 с без событий уходит комментарий `: keep-alive`. Сообщение:

```
event: job.progress
data: {"type":"job.progress","payload":{...}}
```

У заданий в `payload` обычно есть `job_id`, `project_id`, `page_id`, `kind`.

| Событие | Когда |
|---------|--------|
| `job.started` | Задание взято в работу |
| `job.progress` | Прогресс: `progress`, `stage`, иногда `status` |
| `page.updated` | Документ или картинки страницы обновились. Есть `plan` (`clean`, `typeset`, `none`, `export`), иногда `version` или `paths` |
| `job.finished` | Задание завершилось |
| `job.failed` | Ошибка, в payload есть `error` |
| `job.cancelled` | Задание снято |
| `worker.restarting` | Процесс воркера перезапускается |
| `worker.failed` | Процесс воркера завершился или превышен лимит перезапусков. В payload есть `reason` |
| `model.progress` | Скачивание модели: `kind`, `done`, `total` (и те же числа как `done_bytes`, `total_bytes`) |

Имя `llm.status` объявлено в `src/app/events.py`. Сервер шлёт его после фоновой проверки при старте. Интерфейс также берёт статус из bootstrap и из `POST /api/llm/check`. Пока проверка не закончилась, `ok` равен `null` и баннер не показывается.

## Горячие клавиши

Источник — `web/js/keys.js`. Однобуквенные клавиши работают вне полей ввода и только если в настройках включены `single_key_shortcuts` (по умолчанию да). Поле ввода — `input`, `textarea`, `select` и `contenteditable`.

Пока открыт модальный диалог, обрабатываются F1 и Escape. Пока открыты настройки или фокус в поле, не работают пробел, листание страниц, стрелки, Delete, скобки и однобуквенные клавиши. Сочетания с Ctrl из таблицы ниже в поле ввода доходят, кроме Ctrl+Z и Ctrl+Y.

F5, Ctrl+R, Ctrl+P и Ctrl+F перехватываются. Ctrl+R и F5 пропускаются, когда интерфейс в состоянии `offline`.

| Клавиши | Действие |
|---------|----------|
| F1 | Список горячих клавиш |
| Esc | Закрыть меню или диалог, отменить настройки, остановить обработку или снять выделение региона |
| Ctrl+O | Открыть файлы |
| Ctrl+Shift+O | Открыть папку |
| Ctrl+E | Экспорт |
| Ctrl+, | Настройки |
| Ctrl+Enter | Перевести страницу |
| Ctrl+Shift+Enter | Перевести всё |
| Ctrl+Z | Отмена |
| Ctrl+Y | Повтор |
| Ctrl+0 | Вписать в окно |
| Ctrl+1 | Масштаб 100 % |
| Ctrl+колесо, кнопки ± | Масштаб шагом 5 %, от 10 % до 200 % |
| Клик по процентам масштаба | Вписать в окно |
| Page Up / Page Down | Соседняя страница |
| ← / → | Соседняя страница, если регион не выбран |
| Стрелки | Сдвинуть выделенную рамку на 1 px. С Shift — на 10 px. С Alt — менять ширину или высоту на тот же шаг |
| Delete | Удалить выделенный регион |
| `[` / `]` | Размер кисти на 1 |
| Пробел | Зажать, чтобы тащить холст. Не срабатывает в поле, в настройках, в списке страниц и на кнопке |
| V R B E H | Инструменты: выбор, регион, кисть, ластик, рука |
| 1 2 3 | Виды: оригинал, результат, сравнение |
| M | Слой маски |
| L | Слой рамок |

В списке страниц стрелки вверх и вниз, Home и End обрабатывает сам список (`web/js/pages.js`), пробел выбирает строку в фокусе. Влево и вправо листают страницу, если регион не выбран. Стрелки рамки двигают её, когда регион выбран и фокус не в группе радиокнопок, вкладках, меню, контекстном меню, настройках, мастере или диалоге. Кнопки ± и Ctrl+колесо меняют масштаб на 5 процентных пунктов, от 10 % до 200 %. Клик по подписи масштаба вписывает страницу.

## Защита

Правила ниже относятся к локальному интерфейсу. Удалённый слушатель описан в разделе «Доступ по сети».

- Слушает только `127.0.0.1`. Другой адрес в `serve()` — ошибка.
- `Host` обязан быть `127.0.0.1:<порт>` или `localhost:<порт>`. Иначе 403.
- Пустой или отсутствующий `Origin` допускается. Иной `Origin` должен быть `http://127.0.0.1:<порт>` или `http://localhost:<порт>`. Иначе 403.
- Сессия — случайный token. Страница получает его в `?k=`. Cookie `ilt_session` ставится с `HttpOnly`, `SameSite=Strict`, `Path=/`. Сравнение токена — через `hmac.compare_digest`. Без верной cookie `/api/*` отвечает 401. Исключение — `POST /api/session`, который принимает token в теле и выдаёт ту же cookie.
