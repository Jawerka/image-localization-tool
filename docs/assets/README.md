# Иконка приложения

`app-icon-master.png` — исходник высокого разрешения с прозрачным фоном для README и оформления проекта.
`../../web/icons/app-icon.png` — версия 256 × 256 для вкладки браузера.
`../../apps/desktop/windows/runner/resources/localization_icon.ico` — иконка Windows с размерами 16, 24, 32, 48, 64, 128 и 256 пикселей.

Образ: рамка изображения и два речевых облака с символами A и 文 — перевод текста с сохранением рисунка. Палитра: тёмный синий, голубой и индиго.

Исходник создан встроенным image_gen. Уменьшенные версии экспортированы из него без изменения дизайна. Иконка Windows применяется при следующей сборке приложения.
