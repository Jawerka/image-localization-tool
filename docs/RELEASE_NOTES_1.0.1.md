# Image Localization Tool 1.0.1

Обновление доставки рантайма: компоненты теперь ставятся из официальных pip-колёс
(PyPI CDN и PyTorch CDN) — без сборки `.7z`-паков. Размеры в мастере честные
(сумма файлов из манифеста), установка пофайлово проверяется по sha256.

## Что нового

- `torch-cpu` / `torch-cu128` / `argos` скачиваются как официальные колёса;
  манифест schema 2 хранит URL, размер и sha256 каждого файла.
- Первый запуск докачивает только выбранные компоненты — большие файлы
  (cu128 ≈ 2.5 ГБ) идут в фоне, повторный запуск ничего не перекачивает.
- Своё зеркало: `ILT_RUNTIME_MANIFEST_URL` указывает на альтернативный манифест
  (см. `docs/APP.md`, «Загрузка не пошла»).

## Компоненты (скачиваются из программы, в установщик не входят)

| Компонент | Назначение | Источник | Размер | Время (~10 МБ/с) |
|---|---|---|---|---|
| `torch-cpu` | PyTorch CPU: LaMa-очистка без видеокарты | PyPI + PyTorch CDN | ~125 МБ | < 1 мин |
| `torch-cu128` | PyTorch CUDA 12.8: очистка на NVIDIA (RTX 20–50, драйвер **570+**) | PyPI + PyTorch CDN | ~2.5 ГБ | ~5 мин |
| `argos` | Argos Translate: офлайн-перевод (языковые модели Argos качает сам) | PyPI + ассет релиза | ~90 МБ | < 1 мин |

- Без компонентов программа работает: очистка — через OpenCV, перевод — через
  сервер LLM (LM Studio, llama.cpp, Ollama и любой OpenAI-совместимый).
- Компоненты ставятся в «Настройки → Компоненты» или на шаге мастера
  «Компоненты». На NVIDIA с драйвером 570+ рекомендуется `torch-cu128`:
  после установки `auto` сам выбирает CUDA.
- Нужен доступ в интернет к `files.pythonhosted.org`, `download.pytorch.org`
  и `github.com`; используется системный прокси.

## Сервер

Windows: распаковать `server-win64.zip`, запустить `deploy.cmd` (скачает
модели и компоненты, затем поднимет API на порту 8765).
Linux: распаковать, `./deploy.sh`. Без окна: `--deploy cpu|argos|all`.

## Проверка загрузок

`SHA256SUMS.txt` содержит контрольные суммы всех ассетов релиза. Каждый файл
компонента дополнительно проверяется по sha256 из
`ilt-runtime-manifest-1.0.1.json` при установке в программе.

## Известное

- Первый запуск с компонентами скачает заметный объём (до ~2.5 ГБ для cu128) —
  это ожидаемо; загрузка идёт в фоне, окно можно закрыть.
- Если CDN недоступен из вашей сети — см. `docs/APP.md`, «Загрузка не пошла»
  (повтор, лог, своё зеркало).
- Антивирусы иногда придираются к `.pyd`/`.dll` внутри компонентов; при ошибке
  установки добавьте папку программы в исключения.
- ROCm (AMD) и Intel-ускорение в 1.0.1 отсутствуют.
