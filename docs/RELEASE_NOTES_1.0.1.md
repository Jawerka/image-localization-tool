# Image Localization Tool 1.0.1

Исправляющий выпуск линии 1.0. Тег `v1.0.0` и её архивы не заменяются.

## Исправления данных

- Атомарная замена `.ilt.zip` без предварительного удаления старого файла.
- Уникальные имена исходников при импорте пакета.
- LAN-кэш учитывает исходный язык и отпечаток настроек.
- В пакет входит снимок `auto.json`; без него «Сбросить правки» недоступен.
- Диалог Flutter совпадает с форматами сервера.

## Комплект

Windows x64 portable CPU full и light, Linux amd64 Docker CPU full, Chromium ZIP, серверные архивы Windows/Linux, CLI. Firefox ZIP экспериментален и входит в gate. CUDA, ARM, магазин расширений и новые возможности roadmap не входят.

После публикации в GHCR остаётся только принятый образ `1.0.1-cpu-full` (и стабильный тег `cpu-full` на том же digest `sha256:16a8a0f3f06c3bd5fc8dcb58a51fe96b23c3b1d1ff72b1ec5b894ad7d4d136ab`). Тег `1.0.0-cpu-full` снят и отвечает 404: установка 1.0.0 через этот тег больше не работает. Офлайн ZIP 1.0.0 остаётся на релизе `v1.0.0`.
