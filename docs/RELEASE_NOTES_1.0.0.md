# Image Localization Tool 1.0.0

Первый универсальный релиз: базовая программа лёгкая (~150–200 МБ), а тяжёлые
рантаймы (PyTorch, Argos) скачиваются отдельно — как в ComfyUI. Модели
(детектор, LaMa, шрифты) программа по-прежнему докачивает сама при первом запуске.

## Что выбрать

| Файл | Кому |
|---|---|
| `ImageLocalizationTool-1.0.0-windows-x64-setup.exe` | Обычная установка на Windows 10/11 x64. Мастер при первом запуске предложит компоненты. |
| `ImageLocalizationTool-1.0.0-windows-x64-portable.zip` | Портативно: распаковать в любую папку, всё (настройки, модели, компоненты) хранится внутри. |
| `ImageLocalizationTool-1.0.0-server-win64.zip` | Сервер Windows: `deploy.cmd` скачает модели и компоненты и запустит headless-API. |
| `ImageLocalizationTool-1.0.0-server-linux-x64.tar.gz` | Сервер Linux: `./deploy.sh`. |
| `ilt-extension-chromium-1.0.0.zip` | Расширение для Chrome/Edge/Яндекс.Браузера (распаковать и «Загрузить распакованное расширение»). |
| `ilt-extension-firefox-1.0.0.zip` | Расширение для Firefox (about:debugging → «Загрузить временное дополнение»). |

## Компоненты (скачиваются из программы, в установщик не входят)

| Компонент | Назначение | Размер |
|---|---|---|
| `torch-cpu` | PyTorch CPU: LaMa-очистка без видеокарты | ~170 МБ |
| `torch-cu128` | PyTorch CUDA 12.8: очистка на NVIDIA (RTX 20–50, драйвер **570+**) | ~1.2–1.5 ГБ |
| `argos` | Argos Translate: офлайн-перевод. Языковые модели (по паре языков) Argos скачивает сам | ~100 МБ |

- Без компонентов программа работает: очистка — через OpenCV, перевод — через
  сервер LLM (LM Studio, llama.cpp, Ollama и любой OpenAI-совместимый).
- Компоненты ставятся в «Настройки → Компоненты» или на шаге мастера
  «Компоненты». На NVIDIA с драйвером 570+ рекомендуется `torch-cu128`:
  после установки `auto` сам выбирает CUDA.
- AMD и Intel в 1.0.0 без ускорения — только CPU-компонент.

## Сервер

Windows: распаковать `server-win64.zip`, запустить `deploy.cmd` (скачает
модели и компоненты, затем поднимет API на порту 8765).
Linux: распаковать, `./deploy.sh`.

## Проверка загрузок

`SHA256SUMS.txt` содержит контрольные суммы всех ассетов релиза. Рантайм-паки
дополнительно проверяются по sha256 из `ilt-runtime-manifest-1.0.0.json`
при установке в программе.

## Известное

- CUDA-компонент — большой; ставьте его на быстром соединении, загрузка идёт в фоне.
- Антивирусы иногда придираются к `.pyd`/`.dll` внутри паков; при ошибке
  установки добавьте папку программы в исключения.
- ROCm (AMD) и Intel-ускорение в 1.0.0 отсутствуют.
