# Image Localization Tool 1.0.5

**Статус: draft, кандидат ещё не принят.** Текущие доказательства и гейты — в
[ACCEPTANCE_1.0.5.md](ACCEPTANCE_1.0.5.md). Версия собирает накопленные изменения
редактора, расширения, подготовки компонентов и развёртывания. Перед публикацией
нужна приёмка на Flutter EXE и чистых профилях; до неё зелёные unit/UI-тесты не
считаются приёмкой релиза.

## Что нового

- **Инспектор и работа с текстом.** Переработаны карточки региона, поиск шрифта,
  состояния «есть правки / сохранено / обновляется», ручное перемещение текста и
  mesh-деформация. В web-версии изменения закрыты; для Flutter EXE требуется
  parity-проверка.
- **Вкладки «Страницы» и «Очередь».** Web-интерфейс получил две вкладки с
  сохранением активной вкладки и доступностью с клавиатуры. Flutter-панель
  страниц пока сохраняет прежнюю одноколоночную раскладку.
- **Стабильная кнопка расширения.** Overlay больше не оборачивает картинку,
  учитывает `object-fit`, `object-position`, прокрутку, resize и перенос DOM-узла.
  Синтетический Chromium пройден; Firefox и живой Reddit остаются отдельными
  приёмочными проверками.
- **Первый запуск.** Профили «локально / сервер / офлайн», явный объём загрузки,
  пауза/продолжение, восстановление состояния подготовки и локальный fallback.
  Чистая подготовка на новом профиле ещё не подтверждена.
- **Производительность.** Ограниченный prefetch, LRU-кэш рендера, частичная
  композиция изменённого региона и измерения очереди/I/O/памяти. Оптимизации
  проверены на локальных эталонах; WebView2/Flutter p95 и GPU memory остаются
  гейтом для mesh preview.
- **Развёртывание.** Linux: versioned releases, отдельный пользователь, systemd,
  health-gated update и rollback. Windows: staged update/rollback для portable
  сборки, проверенный изолированным harness. Чистый Linux/systemd-хост и installer
  GUI ещё требуют приёмки.
- **Версии и релизный процесс.** Версия расширения синхронизируется с версией
  приложения при сборке. `release.ps1` проверяет notes и чистоту дерева до
  дорогой сборки.

## Известное

- ROCm (AMD) и Intel-ускорение отсутствуют.
- Компоненты скачиваются отдельно; для cu128 требуется около 2.5 ГБ.
- Ключ LLM передаётся только на указанный `llm_base_url`; в JSON он не пишется.
- Старые проекты и документы должны открываться без миграции; это проверяется
  отдельно на реальном маршруте.
