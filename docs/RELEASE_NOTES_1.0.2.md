# Image Localization Tool 1.0.2

Исправление авторизации LLM: сохранённый ключ API теперь уходит во все запросы
к серверу (OCR, перевод, сокращение). Раньше ключ хранился, но в запросы не
добавлялся, поэтому серверы с обязательной авторизацией (OpenRouter и
совместимые) отвечали `HTTP 401: Invalid API Key`, и страница оставалась без
распознанного текста.

## Что нового

- **Ключ API применяется во всём пайплайне.** Заголовок `Authorization: Bearer`
  отправляется и в `/v1/models`, и в `/v1/chat/completions`. Ключ берётся из
  keyring, как и раньше; в JSON-файлы он по-прежнему не пишется.
- **«Проверить» проверяет ключ по-настоящему.** При заданном ключе шлётся
  минимальный запрос (`max_tokens: 1`): неверный ключ виден сразу, даже если
  список моделей публичный (как у OpenRouter).
- **CLI умеет ключ:** флаг `--llm-api-key`, переменная `ILT_LLM_API_KEY` или
  вручную вписанный `llm_api_key` в `config.json` (команда его туда не пишет).
- Смена ключа в настройках действует без перезапуска: клиенты LLM
  пересоздаются, защёлка «сервер недоступен» сбрасывается.
- Ответы 401/403 не повторяются трижды — быстрее включается офлайн-запасной
  путь (RapidOCR + Argos) с понятным предупреждением.

## Компоненты (скачиваются из программы, в установщик не входят)

| Компонент | Назначение | Источник | Размер | Время (~10 МБ/с) |
|---|---|---|---|---|
| `torch-cpu` | PyTorch CPU: LaMa-очистка без видеокарты | PyPI + PyTorch CDN | ~125 МБ | < 1 мин |
| `torch-cu128` | PyTorch CUDA 12.8: очистка на NVIDIA (RTX 20–50, драйвер **570+**) | PyPI + PyTorch CDN | ~2.5 ГБ | ~5 мин |
| `torch-cu130` | PyTorch CUDA 13.0: NVIDIA, драйвер **580+** | PyPI + PyTorch CDN | ~1.93 ГБ | ~4 мин |
| `argos` | Argos Translate: офлайн-перевод; язык загружается при подготовке | PyPI + raw GitHub | ~90 МБ | < 1 мин |

- Для обработки сначала подготовьте детектор, OCR и шрифты. Очистка OpenCV
  позволяет обойтись без PyTorch; перевод LLM требует вашего сервера.
- Компоненты ставятся в «Настройки → Компоненты» или на шаге мастера
  «Компоненты». На NVIDIA с драйвером 580+ рекомендуется `torch-cu130`, 570–579 → `torch-cu128`:
  после установки `auto` сам выбирает CUDA.
- Нужен доступ в интернет к `files.pythonhosted.org`, `download.pytorch.org`
  и `github.com`; используется системный прокси.

## Сервер

Windows: распаковать `server-win64.zip`, запустить `deploy.cmd` (скачает
модели и компоненты, затем поднимет API на порту 8765).
Linux: распаковать, `./deploy.sh`. Без окна: `--deploy cpu|argos|all`.
Ключ LLM на сервере задаётся через окно/API или файл настроек; для внешних
сервисов вроде OpenRouter он теперь уходит во все запросы.

## Проверка загрузок

`SHA256SUMS.txt` содержит контрольные суммы всех ассетов релиза. Каждый файл
компонента дополнительно проверяется по sha256 из
`ilt-runtime-manifest-1.0.2.json` при установке в программе.

## Известное

- Введённый ключ уходит на указанный адрес LLM — проверяйте `llm_base_url`
  перед вводом ключа.
- Публичный `/models` (OpenRouter) отвечает без ключа; итоговую пригодность
  ключа показывает кнопка «Проверить» (минимальный запрос) и сама обработка.
- Первый запуск с компонентами скачает заметный объём (до ~2.5 ГБ для cu128) —
  это ожидаемо; загрузка идёт в фоне, окно можно закрыть.
- Антивирусы иногда придираются к `.pyd`/`.dll` внутри компонентов; при ошибке
  установки добавьте папку программы в исключения.
- ROCm (AMD) и Intel-ускорение в 1.0.2 отсутствуют.
