# Image Localization Tool 1.0.2

Исправляющий выпуск линии 1.0. Теги `v1.0.0` и `v1.0.1` и их архивы не заменяются.

## Исправления ретуши и OCR

- Автоматическая маска дополняет найденные области светлыми буквами и обратной обводкой.
- Прозрачные плашки сохраняют рисунок при ретуши вместо однотонной заливки.
- Смешивание у края маски не возвращает тонкие исходные штрихи.
- Фильтр краевого рисунка звуков сохраняет подтверждённые тонкие внутренние компоненты.
- RapidOCR не назначает роль звука короткой фразе заглавными только из-за регистра; адреса автора остаются подписями. Короткие и повторяющиеся звукоподражания (`BA- DUMP`, `BANG BANG`, `HA HA HA`) сохраняют роль звука.
- В релизной базе закреплены оба пакета OpenCV 4.13.0.92: `opencv-python` и `opencv-python-headless`.

## Комплект

Windows x64 portable CPU full и light, Linux amd64 Docker CPU full, Chromium ZIP, серверные архивы Windows/Linux, CLI. Firefox ZIP экспериментален и входит в gate. CUDA, ARM, магазин расширений и новые возможности roadmap не входят.

Живой образ после публикации — `ghcr.io/jawerka/image-localization-tool:1.0.2-cpu-full`; стабильный тег `cpu-full` указывает на тот же принятый digest. Теги и архивы 1.0.1 сохраняются для отката. `edge-cpu-full` не публикуется.

## Известные ограничения

- Сложные японские и сильно стилизованные надписи на sound-ref (1) и (5) по-прежнему пропускаются OCR. Непрочитанный регион не считается успешно очищенным.
- Универсальные 95% качества на произвольных страницах не заявляются.
- CUDA в готовой CPU-поставке не входит.
- T011 фичи 003 (видимое улучшение на реальном читаемом SFX с воспроизводимыми остатками) остаётся открытым.
