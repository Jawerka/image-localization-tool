# Image Localization Tool 1.2.0

Расширение теперь показывает перевод изображения прямо на странице: без боковой панели и без изменения `src`/`srcset` сайта. Версия включает полные Windows и Docker-поставки, Linux-сервер и обновлённые расширения Chromium/Firefox.

## Что нового

- **Перевод на месте изображения.** ПКМ, ручной выбор или кнопка при наведении запускают существующую очередь и рисуют результат поверх выбранной картинки.
- **Кнопка при наведении.** В безопасных режимах у содержательной картинки через 250 мс появляется компактная кнопка перевода в правом верхнем углу её рамки. Она не меняет разметку и размеры страницы.
- **Панель результата внутри рамки.** «Перевод готов / Оригинал / Убрать» располагается в правом верхнем углу видимой части изображения. В покое прозрачность 10%, при наведении или фокусе — 95%; ошибки и запрос доступа показываются полностью. Для маленьких или сильно обрезанных картинок панель остаётся над рамкой.
- **Доступ один раз.** Оба манифеста объявляют `host_permissions: <all_urls>`; браузер может один раз предупредить при установке или обновлении, но подтверждение больше не запрашивается для каждой картинки.
- **Совместимость.** Поддерживаются `img`/`picture`, одиночный CSS-фон и читаемый canvas; результат следует за прокруткой, изменением размера, dialog и iframe. Смена источника или удаление цели отменяет устаревший результат. «Оригинал» переключает сравнение без нового запроса, «Убрать» удаляет результат.
- **Исправление Windows updater из 1.1.0** входит в поставку: список пользовательских каталогов сохраняется при staged-обновлении и откате.

## Установка

- **Windows, полный CPU-пакет:** `ImageLocalizationTool-1.2.0-windows-x64-portable-cpu-full.zip`. Модели и runtime уже внутри, начальная загрузка не нужна.
- **Windows, лёгкий пакет:** `ImageLocalizationTool-1.2.0-windows-x64-portable.zip`. Компоненты скачиваются при первом запуске.
- **Docker:** `ImageLocalizationTool-1.2.0-docker-cpu-full.zip` или образ `ghcr.io/jawerka/image-localization-tool:1.2.0-cpu-full`; готовый Compose — `compose.ghcr.yaml`.
- **Расширение:** `ilt-extension-chromium-1.2.0.zip`, `ilt-extension-firefox-1.2.0.zip`. После обновления распакованного расширения нажмите «Перезагрузить» и обновите вкладки сайтов.

## Ограничения

- Режим «Кнопка при наведении — совместимость» сохраняет прежнюю замену `src`; новая безопасная кнопка работает в режимах контекстного меню и ручного выбора.
- Сложные `rotate`/`skew`/`clip-path`, защищённый canvas и картинки с неподдерживаемой геометрией показывают предупреждение или остаются без подмены.
- Профиль остаётся CPU x64, en↔ru; CUDA, ARM и LLM в поставку не входят.
- Панель результата намеренно почти невидима в покое; на неё нужно навести курсор. На сенсорных экранах она показывается полностью.
